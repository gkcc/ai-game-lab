# 条件教师任务模型：预留种子官方对照

本实验在读取任何对局结果前，沿用训练阶段已经预留的 2941010634 和 3774915423 两个种子，固定 round2 对手并交换席位。新条件教师任务模型与旧完成筛选任务模型各打 4 场，共 8 场；作物模型、控制器和官方规则引擎保持冻结。种子仅在先前列明的元数据及公开文本范围内排除碰撞，不能保证外部或已删除历史从未使用。

每场必须使用固定官方引擎完整运行 720 个状态和 719 次行动，双方 DONE 且无错误。保留本地 replay，并按已有设施逐回合核对新旧模型与对手动作、状态、背包顺序、语义摘要及最终结算；两个模型臂均须有正数任务前向次数，且调用次数符合冻结预算。证书中的 live 和 primary 计数来自同一重建累计计数及逐回合 trace 对照，并非两套独立现场计数。

预算为 8 场、8 次主复演及 1 次固定独立子进程复演，共最多 12223 个官方状态转移。独立复演预先指定第一颗种子的 candidate、round2、席位 0，使用同一官方引擎及共享校验器，不是另写的独立规则引擎；它还从完整 trace 按固定哈希选择 20 个回调，核对观测、配置和请求投影。

按同种子同席位配对报告自身净收益、对手净收益、现金差、胜平负和得分，种子而不是席位或对局是独立聚类单位。既定非退化护栏为：每颗种子两席的平均自身净收益差和现金差均至少 −1000；每席两项差均至少 −2000。两种子、一对手仅用于探索性筛查，不能证明统计显著、普遍优势或自动晋级。

每场和独立复演采用仅管理自有进程的 Windows Job 采样监督，清理不确定、身份或规则校验失败即停止，不重试或补种；采样不能保证硬实时内存上限。新旧模型和默认 Bot 不修改，原始 replay、trace、权重、个人路径和日志只保存在本地。
