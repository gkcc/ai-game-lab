# 固定锚定更新重接 V1：真实训练与比赛完成，候选不晋级

本轮完成一次实际 GPU 训练、24 场新开发和 96 场新留出官方完整比赛。
候选相对原任务学生的平均净收益增加约 **0.996%**，但事前规定的 95% 种子聚类
区间跨过零，**未证明可靠提升，不收录为新教师、不修改默认 Bot**。
这不是证明方法没有收益；现有证据未达到已经冻结的晋级条件。

## 新比赛结果

新开发 2 个种子、留出 8 个种子，均与可见旧登记、失败和未使用保留种子排除重合。
每种子对 `round2`、`market` 两个冻结对手交换席位，分别运行 S/C/T。
S 为原任务网络；C 为本轮候选；T 为**规则任务选择加同一冻结选种网络**，不是原全规则教师。

24 场开发阶段 C 对 S 平均净收益 +1.234%，对 T +1.074%，通过进入留出的门槛。

唯一未通过的 S 晋级门槛是自身收益区间下界必须大于零。其余均值、比赛得分及对手点估计
保护条件通过，但不能因此覆盖这个失败条件。胜率没有提高。
T 的自身收益保留门槛通过也不代表全面不退步：C − T 的现金差均值为 -609.75，
95% CI 为 [-1342.69, -27.81]。账目上 C 自身少 140.50，对手多 469.25；
这只是现金关系，未将它拆成独立机制的因果份额。

32/32 场 C 留出局在同一分歧前状态改变了完整请求，证明模型实际控制行为；
动作改变不等于收益改善。对手点估计保护条件也不等于逐对手统计非劣保证。
所有公开配对明细和置信区间均保留在统计证据中，不把 96 场当成 96 个独立随机样本。
