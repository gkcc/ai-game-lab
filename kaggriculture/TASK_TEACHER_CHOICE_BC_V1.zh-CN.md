# 条件教师任务选择 BC：预登记

本阶段探索一个与旧完成证据筛选不同的监督目标：在既有任务候选集合上学习冻结教师当时会选择哪个候选。八份来源是已审计的历史开发对局，混合 baseline、candidate 和 teacher-task 控制器；教师是在这些控制器形成的状态及已建立的预留上下文中作出的选择，不能称为纯教师轨迹，也不能视为该教师动作已经执行或完成。

每份来源都有绑定相同 trace 和 replay 哈希的 719 回合冻结 actor 重建证据，比较包含教师标签及输入。新采集会再按实际压缩字节流核验 trace 哈希，并验证每回合顺序、实际选择、合法观测投影及候选身份。教师标签必须唯一属于候选集；模型只接收共享和候选数值特征，不接收标签、seed、教师优先级或对手私人状态。旧的 completed 和 unknown 状态不参与本次训练。

在读取数据前，固定按游戏、回合和回调序号的 SHA256 选择约八分之一的机会，选择规则不使用标签、收益或模型表现。上限为八份 trace 各一次完整解码、128 MiB 压缩输入、2 GiB 解码输入、单行 16 MiB、4000 组及 250000 个采样候选；单组 8192 候选的上限只作用于采样回调。少于 256 组、任一训练种子少于 32 组、或教师所选操作少于三类时停止，不进入训练。

通过后最多进行一次 128 步同步 JAX GPU 训练，只封存最后一次更新；16 组做请求最高精度的 GPU/CPU 推理对照。本阶段不使用验证集选择检查点，也不作竞技提升结论。Windows 采集使用独立 Job 采样监督；WSL 训练由 Linux 会话及 Windows 传输分别留证，Job 验证不能外推至 WSL 或 GPU 显存，采样与禁预分配均不是硬内存上限。训练归档使用有界不可变字节快照，快照、数组和副本均会额外占用内存。

在读取训练轨迹前按已识别种子元数据预留 2941010634 和 3774915423；未列出的、已删除或外部历史不在保证范围。后续拟用两个种子、round2 对手、双方席位与新旧模型进行 8 场官方对照：每个种子的双席平均自身净收益差及现金差均不低于 −1000，每席两项差值均不低于 −2000。实施前仍须另行冻结运行器和评估代码；通过也只说明小样本未触及这些退化阈值，不能证明统计显著或自动晋级。

本阶段不跑新比赛、PPO 或 DAgger，不修改默认 Bot、旧模型或官方规则。原始 trace、训练数组、模型、私人路径和日志只留本地；预登记是本地 Git 记录，不是第三方时间戳。

## 采集与训练结果

本地预登记提交 8dd46a5 后，八份历史 trace 各完整读取一次，压缩量 60619731 字节、解码量 836084675 字节。固定抽样得到 2253 组和 118955 个候选；教师所选操作分别为浇水 1816、收获 199、种植 146、施肥 84、开垦 8。两个训练种子分别提供 1128 和 1125 组。它们是混合控制器状态下的条件教师选择，不是任务完成统计。

唯一一次 fit 在 GPU 完成 128 次同步更新，128 次梯度非零，权重相对初始化发生变化；16 组、1128 个候选的 GPU/CPU 推理对照请求最高矩阵精度，最大绝对误差约 0.0000021322。校验不等于测量硬件实际精度。训练约 11.96 秒；该时间不包含完整的数据准备和官方游戏模拟，不能代表系统整体加速。

训练模型已按 SHA 封存，原参考模型与选种模型哈希复核未变。采集 Job、Windows WSL 传输和 Linux 会话分别报告清理通过。独立子代理检查的是源码和聚合收据，没有读取原始数组或模型重算；没有记录训练损失，也没有新比赛或留出结果。模型是否更接近教师、收益是否改善及是否值得晋级，目前均未证明。
