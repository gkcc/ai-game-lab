# 合并示范任务模型：官方对局探索性评估

合并教师示范的任务模型已经完成有限 GPU 训练，但尚无实战收益证据。本阶段冻结该模型、旧未加权任务模型、作物模型、官方引擎及对手，进行一次小规模官方对照；不继续训练或修改策略。

四个新种子分别对 `round2`、`market` 和完整冻结施肥教师，交换双方席位；每个组合由新任务模型、旧任务模型和 `teacher_task` 三个策略臂各打一场，共 **72 场**。三个策略臂共用同一个冻结作物模型和控制器；`teacher_task` 是规则任务选择配合作物模型，不能称为完整施肥教师。完整施肥教师是独立的第三个对手。

种子从 `[1000000000, 4294967295]` 中按系统随机方式选取，排除可识别的历史训练、对局、失败面板及预留记录；未识别、已删除、外部或不可访问的历史仍无法排除。赛前仅公开四个种子的数量、带随机盐的承诺和私有文档哈希，文件名与公开材料使用 `S01` 至 `S04`；面板结束后才揭示种子与盐以供复算。承诺格式为 `SHA256(domain || 32字节盐 || 四个大端uint32)`，domain 以源码中的终止零字节为准。承诺不证明操作者双盲，也不是可信第三方时间戳。

每场调用固定官方引擎，要求 720 状态、719 次动作、双方 `DONE` 和零 Agent 错误，保留本地 replay 并进行 719 步主复演；另外预选 `S01/round2/merged/0号席位` 做一次独立进程复演和 20 个确定性回调检查。复演共用官方引擎及部分校验器，不是独立规则实现，也不独立重算网络推理。官方模拟和模型推理由 CPU 执行。

分别报告每个对手和策略臂的双方净收益、现金差、胜平负与比赛得分；按相同种子、对手和席位配对比较 `merged−unweighted` 与 `merged−teacher_task`。只对前者使用预定探索护栏：每个配对的自身净收益差和现金差均不低于 −2,000；每个种子／对手的两席平均差均不低于 −1,000；总体自身净收益、现金差和得分差均不得为负。只有护栏通过且总体自身净收益、现金差均为正，才标记探索性正向信号；这不是自动晋级，也不表示优于完整教师。

使用完整种子为聚类单位，每个簇保留全部对手与席位，固定 10,000 次 bootstrap 并分别报告对手结果。四个簇只能描述风险，不能证明统计显著或泛化。完整面板与额外复演都通过后才计算经济统计；任何失败都保留证据并停止，不补场、换种、重试或以部分成绩筛选策略。

每场前连续三次、间隔十秒检查主机可用内存至少 4 GiB，运行时采样底线 2 GiB，单场 Job 限时 900 秒；每场 Python 写入预算 128 MiB，阶段实时占用上限 10 GiB，磁盘空闲底线 4 GiB。此前 24 场约占 1.74 GiB，不能保证本轮实际体积；采样与 Python 写入限制不是操作系统硬配额。全局截止在单场前后和复演回调中检查，运行中的 Job 可能继续到退出或自身限时，不能称为硬实时全局中断。

Python 标准输出及错误输出被丢弃，Win32 原生输出句柄未独立实测；原始 replay、私有观测、日志、模型与赛前种子文件留在本机。静态输出目录链接检查也不构成防止同用户并发替换的安全边界。事前独立子代理审查通过，未实际运行本轮比赛；实际结果以之后的收据和账本为准。
