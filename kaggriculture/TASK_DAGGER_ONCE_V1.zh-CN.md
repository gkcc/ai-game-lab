## 研究问题与事前冻结

S 是原任务网络加已冻结的改进选种头；T 是规则任务调度加同一个选种头，不能称为原始全规则教师。C 从 S 的任务权重热启动，保留候选空间、特征、原归一化、选种权重及运输、市场等规则。它只在教师已有的经营机会内选择，并未扩展到完整官方动作空间。

监督标签来自 S 实际比赛中每次回调的当前候选集合和资源预留上下文。不同轨迹不按回调序号对齐，标签、教师优先级、种子和对手私有信息不进入模型数值输入。所有完整候选组均保留，既不只收集分歧样本，也不按收益筛选。标签 ID 分歧不等于错误动作、唯一最优性或经济损失。

登记最多 136 场：16 场训练 S、24 场开发 S/C/T、96 场留出 S/C/T。先通过首个训练种子的四场入口与监督数量检查，再完成训练及开发 S 状态采集；只有固定离线检查通过才运行开发 C/T，开发经济门槛通过才运行留出。所有停止条件均在读取结果前固定。

## 为什么停止

| 固定离线指标 | 初始 S | 最终 C | 比率与判定 |
| --- | ---: | ---: | --- |
| 新开发状态的条件加权 CE | 0.1483080143 | 0.1332886054 | 0.898728，要求 ≤0.95，通过 |
| 原验证集的条件加权 CE | 0.2243611397 | 0.2300069749 | 1.025164，要求 ≤1.02，未通过 |
| 新开发状态候选 top-1 | 96.5872% | 97.1663% | 描述性指标，不替代 CE 门槛 |
| 原验证集候选 top-1 | 94.0065% | 94.1910% | 描述性指标，不替代 CE 门槛 |

新状态加权损失下降约 10.127%，但原验证损失增加约 2.516%，超过允许的 2%。没有因只差少量而放宽阈值。top-1 同时上升与加权 CE 恶化并不矛盾；这里不能推导出实际比赛能力退化了 2.516%，也不能用准确率上升替换原验收标准。

17,786 个开发候选组的导出重载 CPU logits 逐位一致；CPU float64 与 GPU float32 的 955,200 行 logits 最大绝对误差约 0.000063213，小于登记容差，首 argmax 分歧为零。原始在线观测与缓存 float32 表示的区别仍保留：这项离线检查不证明 C 已接入完整官方对局。

运行器以 `stopped_offline_gate` 正常退出：24 次尝试全部完成；一次拟合完成；C/T 开发局零、留出局零、重训零。八个登记留出种子没有运行，仍是已登记保留种子，不能在下一任务改称此前未登记的新种子。本轮没有比赛配对收益、胜率提升或聚类置信区间，也没有完成新权重控制完整比赛的证明。

## 审计、成本与证据边界

39 项纯 CPU 针对性回归通过，Linux 进程监管正常/超时/取消三个真实路径通过。独立预审分为原 38 项和隐私修正后的 11 项聚焦复审，其中十项重复，不应相加称为 49 项不同测试。

首次发布检查发现两处具体设备名称，尚未提交或运行实验时即拦截。设备条件移入 SHA 绑定的本地私有配置，源码从同一份已校验字节读取；只改四个文件，种子、算法、预算和门槛不变。原冻结、原预审和修正映射均保留。备份清单有一个无效自身哈希行，原文件未改，新预审明确排除此行并单独绑定清单实际哈希；其余 11 份旧备份均核验一致。

实战与主要复演各 17,256 次官方转移。独立预选首训练种子 round2 席位 0 的 S 额外复演 719 步，合计 35,231 步；后续 C/T 样本阶段未到，不替补其他样本。24 场独立原始终局、语义及 trace 核查已通过；其标签检查核对当前候选和资源预留绑定，没有额外重新生成教师 priority。

主流程网络计算共 108,778 次任务前向、7,728 次选种前向，共 5,673,826 输入行；包括实际对局、主要审计和两场原学生一致性检查。控制器与对手调用共 70,462 次。训练各呈现 65,536 组旧/新训练数据，真实候选行 6,725,482，含 padding 呈现行 13,372,676；这是 value-and-gradient 输入量，不是 FLOPs。主离线 CPU/GPU 评分共 6,527,324 行，独立抽检另计。全运行机器阶段约 836.031 秒，包含采集、缓存、训练和审计，不是纯环境吞吐。

独立历史核查确认 122 个冻结运行文件及其登记提交中的发布对应关系、2,318 个受保护源码和模型内容哈希、1,148 个旧公开文件内容，以及 16,757 个历史路径的大小和修改时间。历史路径的 stat 核查不等于重新散列全部旧 Replay；发布前另以原 Git blob 核对旧公开内容，只允许两份进度文档追加。

独立代理核验了 32 个缓存数组的实际哈希、初始/最终参数、归一化及训练收据；用另写的前向公式对四个 split 的预定前缀各取 64 个完整组、4,897 行，执行两个模型×CPU/GPU，实际评分 78,352 行，数值容差与首 argmax 一致性均通过。合计主流程和独立离线评分为 6,605,676 行，低于登记上限。这是重复平台/模型的评分量，不是 78,352 个不同状态；三个 split 的归一化输入前缀相同，覆盖局限于确定性开局，未补选更有利的样本。

完整保存的最终开发 CPU/GPU logits 已独立重算 CE、首 argmax 和误差。初始开发及原验证集的完整 logits 未保存，其全量 CE 仍来自主训练记录；独立复核只重算记录标量的比率与门槛，并做上述数值抽查，没有冒称全量重算旧验证损失。512 步历史训练根据冻结源码、进度、收据、设备身份和实际权重核实，没有重新训练。所有结果证书来自同一位独立结果审查者，不能按文件数声称有多位审查者。
