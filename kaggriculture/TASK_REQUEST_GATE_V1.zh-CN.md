# 整回合教师请求收益选择器 V1：早期信号门槛未通过

本轮完成了 11 场官方完整比赛，按事前登记在第二个训练种子后停止。没有拟合新选择器，没有进入开发或留出比赛，也没有证明策略改善。默认 Bot、冻结教师、两个既有网络和历史结果保持不变。

## 研究问题与冻结

本地事前登记提交为 `517d7b60f5729af6896ec5a386bdd455a65984ad`，在新比赛前完成，不是第三方时间戳。规则提交仍为 `f994f2050d58d84f649329c1e35ce09ada7007c5`。登记、种子和完整源码身份见 `review/evidence/task-request-gate-v1-20261027/`。

S 是原有任务网络加选种网络学生。T 使用规则任务选择，但保留同一个选种网络，因此不是原始全规则教师。二者在同一合法观测上分别生成完整的 farmer、hands、有序 market；只允许选择其中一个完整对象，不拼接字段，不修改权重或官方规则。

训练对局预先分配 80–119、260–299、440–479 中的一个窗口，取窗口内第一个完整请求确实不同的回合。A 全局使用 S；B 只在该回合使用 T，随后恢复 S。若窗口没有差异，该单元保持缺失，不补种子、窗口或干预局。主要标签是 B 相对 A 的终局双方现金差增量；自身收益、对手收益和比赛得分分别保留。

原计划最多 176 场：训练 64、开发 16、三臂留出 96，逐阶段设门槛。首先要求前两个训练种子的八个单元中，至少四个有效配对，且至少一个非零现金差结果。本轮在这一步停止，后续完整训练、单次九参数 CPU ridge、开发和留出门槛均未启动。

## 执行成本与证据边界

实战和主要复演各 7,909 次官方状态转移。现有网络共执行 51,908 次任务前向、3,818 次选种前向，合计 2,718,064 个输入行；包括实际策略、未提交的教师提案、主要审计及两场原学生一致性检查。完整控制器与对手计算合计 33,526 次，额外教师提案 452 次，门控预测为零。机器阶段约 402.438 秒，包含比赛、推理、写盘和审计，不是纯仿真吞吐测试。

31 项针对性回归和独立预审通过。预审只修正了全程 T 臂的任务模型身份记录：该臂不构造任务网络，逐场身份应为 null；原冻结和修正映射保留。实际尚未运行全程 T 留出臂，因此不能将源代码检查描述成该臂的实战验收。

独立子代理核对了全部 11 份原始 Replay 的初始和终局现金、DONE、奖励，逐场完成标记、源码/回放/追踪哈希，全部追踪计数、配对结果和停止条件；并对事前指定的首个种子 round2 席位 0 基线额外官方复演 719 步。该单元没有干预局，未补选其他样本；独立复演不覆盖唯一非零收益的另一种子。总官方状态转移为 16,537。独立复核未新增模型读取、神经前向、拟合或比赛；三份审查证书均来自同一子代理，不能写成三位审查者。

冻结登记提交绑定、107 项运行/发布文件对应关系通过；四项历史文件只有已登记的 CRLF/LF 差异。历史保护实际检查为 2,303 个源码内容哈希和 16,555 个历史路径的大小/修改时间，并非重新散列全部历史 Replay。旧公开文件另以原 Git blob 做发布前保留核查。

原始 Replay、HTML、观测、动作、提案特征、追踪和日志只保留本地。公开版本仅含脱敏经济账本、删除特征的配对结果、聚合证书、源码与哈希。

## 阶段结论

本轮确认了完整请求分歧的采集与配对路径可以执行，但该单回合干预设计在早期样本中没有达到足够的信息量。关闭此分支，不补样本、不降低门槛、不重复同类单回合门控试验来追逐正结果，也不消耗本轮留出种子。后续需由独立规划与现有证据选择新的有界任务；不能据此直接跳入 PPO。
