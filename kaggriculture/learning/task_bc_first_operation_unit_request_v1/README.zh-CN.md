# 首个操作类别分歧的单位请求实验

上一轮六个 WATER／WATER 首分歧只改变了同轮任务分配顺序。本轮仅检查固定历史来源 `holdout-1714414373-v1-0-trained` 的最早操作类别分歧：把其中一个当前合法的条件教师选择替代学生选择后，完整有序单位请求是否改变。历史名称含 holdout，但种子已经消费，本轮不是独立测试、收益评估或教师优劣判断。

样本算法在数据读取前固定。独立选择器是唯一旧 compact 和投影 receipt 读取者：投影收据一次读取、原 SHA 校验；compact 单次打开、全 923,156 字节增量 SHA，只解码到第一处 `teacher.op != chosen.op` 的前缀，最多 691 条。后缀只计原字节和换行，不 JSON 解码、不再选样。安全旧汇总表明 step 0–239 有一处操作分歧，其条件教师类别为 WATER；实际回合、索引和学生类别仍须由冻结后的选择器确定。

完整 SHA 符合后，主探针才读取唯一 gzip 前缀到目标 step+1，最多 240 行，只解码一条目标 JSON，核对原字节行 SHA。每个已解码的嵌套对象均计数，即使没有用于决策。完整 trace SHA 为继承证据；前缀关闭不宣称 EOF，内部未返回解压缓冲量保留计划 unknown，失败未知量另列。

原任务模型和选种模型各原 SHA 校验、加载一次。先从原事实观测完成一次学生基线，精确复现全语义 trace、选种、预留和单位向量，仅排除原选种计时字段。然后从同一事实状态再调用一次，在目标回调改选当前合法教师候选，立即恢复原学生并重新枚举、评分后缀。更早的学生／教师候选身份分歧允许保留；它们只需操作类别相同，不能强迫学生前缀改为教师。完整的 `[farmer, *hands]` 按单位编号比较，不排序为动作集合。

旧所有源码保持原字节。新 `probe.py` 只覆盖操作类别与事实前缀判断，复用原模型 I/O、前向计数、完整基线核验和调用收据；新 `source.py` 复用旧压缩字节计量及嵌套对象计数；独立选择器和核对器不调用主探针来得出相等结论。Windows 所属进程树运行器继续复用，不重建训练或审计平台。

连续可执行预算为 120 秒：选择阶段至第 15 秒，主任务至第 80 秒且本阶段最多 65 秒，独立核对至第 100 秒且最多 20 秒，最终收尾至第 120 秒。每阶段原有最多 10 秒关闭时间包括在该截止内；一个 worker、单线程数值库、1 GiB Job 私有提交上限。全部基线／干预合计最多两次控制器调用，每次检查 10 秒上限。任务头最多 31 次前向／15,872 个评分候选，作物头最多 32 次前向／160 个 logits 数值，不缓存评分、不做 warmup。最多五个微型内存协议用例在同一次执行内完成，没有临时文件或额外测试体系。

源压缩读取最多 6,825,738 字节、返回 payload 最多 64 MiB、单行及目标 JSON 最多 4 MiB。模型读取包含原 SHA、np.load 和 seek 后重读，返回字节总计最多 4 MiB。累计旧任务评价 3,910 组／228,122 候选不退款，完全耗满新上限也不超过 3,941／243,994。

独立核对器只读本轮选择、主收据和一个私有 pair，各一次，合计最多 512 KiB；它重算首次操作分歧、前缀和合法候选、唯一替换、后续评分序列、完整单位变化和消费。原投影收据不由主探针或核对器重新读取。控制输入另有 256 KiB 总限额：三 worker 读取的 registration＋freeze、父进程最终绑定读回，以及主探针读取的选择收据；冻结时提前核对最坏分配。静态预提交绑定先于可执行阶段；核对器的三份数据收据使用其单独读取额度。最终执行检查还统计新 OUT 内全部文件（包括登记副本、私有日志及失败残留），最多 2 MiB；后续人工复审及发布记录另行标识。

```powershell

```

相同或不同都是有效诊断方向；复现、预算或核对失败则保留实际消费并停止。不补样、重试、修改阈值、自动遍历其他分歧或启动训练／新比赛／官方状态转移。请求不同不代表学生错误、收益损失或教师更优。本轮也不比较市场返回值、官方执行或未来轨迹。

选择证书、完整 pair、坐标、观测、数值特征、模型、原流、日志及进程身份只在本地。公开只发布脱敏计数、结论、源码和哈希绑定；公开哈希不能替代私有原件复算。summary 仍是临时结果，必须有最终绑定验收、父入口零退出、自然关闭的全部所属进程树、无 final-deadline-failure 和 check/failure，才可接受一次执行。旧模型准入失败和历史失败结论始终保留。
