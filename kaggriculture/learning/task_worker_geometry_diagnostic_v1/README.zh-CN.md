# 已消费局面的工人距离与训练示范结构

固定读取已消费面板的 `S02` / `S03`、`round2`、双方席位四条 `merged` trace，检查零基 step 2 的第 6 条任务选择。输入身份复用此前 12 场的私有快照和验收收据；每条压缩 trace 完整校验摘要，只做最初 3 行的 JSON 解析，gzip 内部可能预读后续字节。所选学生候选与**学生先前安排之后的条件教师标签**必须都是同一目标的 `PLANT`、不同单位，并且均在当时可用集合中。若前提不成立，不补选其他记录。

分类器根据合法 actor 观测中的农夫及雇工位置独立计算曼哈顿距离，核对候选的单位编号、单位/目标坐标、距离和五类操作编码；还检查该目标所有 `PLANT` 候选与冻结教师的最近距离、同距编号排序一致。这里“单位”包括农夫和雇工。候选是冻结控制器提供的经营机会，不是官方完整合法动作空间；距离不是实际路径耗时，移动请求不是完成种植。模型输入包含这些特征，不证明模型学会或利用了它们；trace 没有逐候选 logits。

训练部分读取两份登记档案的限长字节快照并校验身份，只解码 `shared`、`candidates`、`offsets`、`teacher_choice_label` 和 `ops` 五个成员，不解码档案里的 seed 成员。角色绑定仍需在本机内存核对既有历史私有种子文档；读取公开训练登记也会解析其既有训练种子字段。这些值均不输出，不读取未消费留出赛轨迹或种子。

按旧/新来源分别统计教师标签为 `PLANT`、同目标不同单位的候选结构。`encoded_step_2` 仅表示保存的共享特征列数值为 2；本轮没有逐条重新核对对应原始观测。档案没有对局 ID、席位或回合内选择序号，不能把相似组当作历史 trace 的同一决策，也无法证明某组当年实际进入训练批次。两个来源均为有选择的条件教师示范，后者还定向采样，不能代表自然比赛分布。是否存在同类示范不证明模型学会规则或改善收益。

本机结果只保存聚合计数，不保存单位编号、坐标、原始特征、真实种子或输入摘要。公开投影有意给出四条固定历史选择的类别总数，不给出单条角色绑定；训练档案只给每个来源的两个早期类别 `below_20` / `at_least_20`，其中 0 与 1–19 不区分，不公开联合类别、总数或其他时间桶。这是固定查询下的披露控制，不构成形式化匿名保证；不能把 `below_20` 理解为一定不存在。

入口核对登记与源码当前字节，绑定已冻结的既有依赖并拒绝常见包遮蔽；操作方仍须在运行前后独立核对已提交的登记和源码身份。程序自身不能证明 Git 事前提交、执行中未发生同用户竞态或抵御任意自定义加载器。180 秒截止在部分步骤采样，档案/trace 字节上限不等于操作系统硬时限或 RSS 上限。原始回放、trace、档案、模型、默认 Bot 和规则不修改；不调用模型、训练、GPU、比赛或官方状态转移。
