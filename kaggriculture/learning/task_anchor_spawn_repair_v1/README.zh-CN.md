# 训练启动边界修复 V1

上一轮 `task_anchor_once_v1` 的唯一正式启动失败：父进程的全局文件写入保护拦截了
Linux `multiprocessing` 的启动管道。pickle 已在内存序列化，尚未传输；真实训练 worker
未到达。本目录提供独立的新启动器，旧代码、证书、尝试额度及失败结论保持不变。

修复只移动保护范围：两份父进程收据分别在窄保护范围内写入，共享累计 65536 字节额度，
失败写入不退款、拒绝后不能开新范围重置额度。进程构造、序列化、IPC、启动、等待、终止与
回收在保护范围之外；目标进程仍单独保护产物。未放开可写描述符、`closefd=False` 或任意文件。

`launch()` 是实际新启动控制函数，回归使用可导入的顶层纯合成目标经过它启动；
没有 mock `Process.start`、管道或清理。目标只接收固定小 payload，写一份 marker 和收据。
尚未将这次修复作为实际模型拟合的成功证据；后续真实学习入口需另登记、另审查。

本轮只允许一次真实 `multiprocessing` 目标启动，不是一次模型训练。
外层另有 Linux 监督进程及 Python 运行辅助进程，它们不算第二次目标实验。
复用已有监督器检查整个自有 session、发送终止信号并回收直接子进程。
外层总 30 秒，工作 15 秒、清理预留 15 秒；目标等待上限 5 秒。
任意启动、存储、清理或历史保护失败就停止，不再启动第二次目标，不用模型替代验证。
异常时保留原始错误及取消、Windows transport、reader、Linux 清理各自的确认状态。
超出 30 秒后的等待只能算失败后的清理恢复，不能计回成功预算；未确认状态保留为 unknown。
如果非 daemon reader 仍存活，入口可能仍在等待它，不能当作进程已经结束或据此重启。

阶段时限 3600 秒，以前轮发布收据时刻作为更早的保守起点。
本轮产物目录总上限 1 MiB（文件内容；不称 OS 配额）：主侧准备/收尾 512 KiB、
父收据 64 KiB、目标 8 KiB、拒绝检查 4 KiB、结果 8 KiB、监督收据 16 KiB、
原生输出捕获 64 KiB、独立审查 256 KiB，合计 932 KiB，剩余为缓冲。
版本化源码与公开交付副本另列，不混同于运行产物限额。

验收必须同时看到目标 marker、真实进程零退出、共享收据额度未重置、目标写入被计量、
描述符及范围外写入仍拒绝、Linux session 清理和旧失败证据保留。
0 模型/缓存数组解码、0 神经前向、0 GPU 运算、0 官方对局；身份哈希核验另列。
已有模型、策略和默认 Bot 不变。不据此推断训练数值正确或策略收益提升。

```text
python -B -m unittest learning.task_anchor_spawn_repair_v1.test_launcher learning.task_anchor_once_v1.test_storage
```

实际 WSL 入口为 `python -B -m learning.task_anchor_spawn_repair_v1.probe guard`。
它需要事先生成的新登记、源码冻结、独立预审及提交收据，不能直接在旧失败目录执行。
启动配置保持私有。原始日志仅本地保存，公开安全摘要、源码及哈希。
Windows 调度使用同目录 `entry` 模块的 `prepare`、`export-pre`、`run` 子命令；
准备和发布操作使用本项目既有的运行目录与单独的 `publication/ai-game-lab` Git 工作区。
该调度器也随源码冻结、公开，不把运行入口只留为不可审查的私人脚本。
