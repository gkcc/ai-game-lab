# 两臂更新的纯内存组合

`train_pair` 仅组合已有资格、批次、打包及两臂更新函数。它从调用方传入的只读训练 mapping 计算资格，一次生成两臂共用批次，每批打包一次，完成调用方指定的完整更新预算后返回两臂权重与粗粒度布尔／计数；不返回抽样索引、簇、种子、特征或标签。控制臂用既有 CE，实验臂附加固定的 0.25 条件工人损失；零独立辅助梯度、任一臂不变化、两臂相同或预算不完整都会失败。

此函数不验证数据来源、逐组语义、特征隐私、checkpoint、设备型号或登记，不负责系统资源／进程监管、写文件、实际部署重载或比赛。只读 mapping 不等于底层文件锁。正式入口须独立认证所有这些前置条件，并事先固定 64×256 与 RTX 设备；该组件不能将传入设备包装成 GPU 验收。

组合器在第一个外部 `check` 回调前，先验证初始模型尺寸和逻辑字节上限，再复制模型参数以及小型归一化和类别权重数组；后续各批共用这些只读快照。快照防止回调或调用方之后修改原数组影响本次执行，但复制时没有跨线程或操作系统锁，不能证明来源身份或抵御并发替换。大型训练数组仍由调用方负责认证和保证持续不可变。

回归只使用玩具数据、显式 CPU、固定 2×8 预算，且在测试进程设置 `JAX_PLATFORMS=cpu`；未读取真实数据或模型，未使用 GPU，不能宣称真实训练或竞技提升。
