# 固定第6步模型的经济诊断

这是一次明确放宽**新诊断准入**的独立登记，不是修改旧实验门槛。全批次输出头实验仍然离线失败、零比赛：固定160处错误剩112，超过80的上限。全部21个头已经看过；本轮只用原验证CE选出的第6步，不能改选其他头。

对照为原已训练学生，并非随机初始网络。两模型保持各自字节不变，同一规则控制器、固定官方引擎；4个新开发种子、3冻结对手、交换席位，共48场，再复现预指定的第一个种子市场对手两席位，共2场官方文件入口。后者不进入统计。

不训练、不新增示范、不重新选模、不追加种子、不替换失败比赛、不晋级。四整种子分别保留3对手与两席位；描述自身净收益、对手净收益、现金差和比赛得分，披露所有分组。探索门槛为四种子的自身收益增量均为正、总体现金差及得分不退步、市场对手的收益/现金差/得分不退步，并通过全部执行检查。四种子不用于宣称显著泛化，一种模型也不能校准原50%错误削减门槛。

运行入口：`python -B -m learning.bc_crop_economic_diagnostic.experiment MODE --out artifacts/bc-economic-epoch6-v1-20261023`。`prepare`另需`--public`，在干净公开仓库上运行；独立预审和本地事前提交完成后才运行`games`、`entries`、`audit`、`analyze`。准备/比赛调度用learning虚拟环境；审计用装有官方游戏引擎的项目虚拟环境。不得绕过已有启动标记重复运行比赛。

`prepare`冻结双方模型、规则、控制器、worker、分析源码、两个子目录配置及旧历史快照。`games`共享4进程和全局失败停止，不开两个独立重试面板；每个子目录使用原审计器认识的`trained`协议，额外`model_family`区分原学生和第6步模型。既有`bc_crop.audit.check`复现双方动作、模型身份及719行稳定轨迹，再调用官方保序复演。独立账目消费者再复演并核验现金闭合，只计实际成交、实际成功种植及终局库存。

原始回放、决策轨迹、权重、设备信息及实际本地启动路径仅留本机。公开脱敏逐场指标、源码哈希、预登记、证书、分组结果与独立审查。事前本地Git提交不是第三方时间戳。
