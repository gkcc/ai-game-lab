# 训练视图的只读适配

`adapt_r8` 将已由调用方认证的原教师 R8 训练 `RaggedView` 映射为既有 `pack_training_batch` 接口需要的八个数组键。它固定组数、候选数、字段、dtype、训练簇数量、分组边界及选中操作；只接受只读数组，保持每个数组的原对象和顺序，不复制大型特征数组。返回的只读映射不能替换键，但并不是文件锁。

训练簇及 schema 身份必须来自事先认证的登记，不能从待校验视图自行推导；调用方仍须核对原始来源、文件摘要、分片顺序和不可变性。相同形状、角色参数或簇值不证明真实来源，也不能排除其他进程修改底层文件。开发集、掩码及教师标签不能作为新增模型特征；本组件不生成批次或训练模型。

本组件不逐组验证特征中的单位／目标与 `candidate_identity` 一致，也无法仅凭簇集合发现两行的簇身份互换。真实训练入口必须绑定已经逐组语义核验的确切源字节和行顺序，或重新逐组执行来源语义检查；仅凭本适配器、资格计算和打包器通过不能证明监督标签正确。簇身份仅用于采样和评估，不作为模型特征。

合成测试不读取真实数据或模型、不使用 GPU 或运行比赛，不代表真实训练已完成。
