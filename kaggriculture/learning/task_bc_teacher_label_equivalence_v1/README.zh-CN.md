# 一个训练状态的标签等价性验证

本阶段检验一件事：实际训练数据只有一个正标签时，是否遗漏了在同一状态、同一前缀下可以得到完全相同当回合请求的另一个候选。不是改 loss、生成新的训练集或训练模型；也不把少量历史诊断当作新的独立留出测试。

固定来源为原训练种子列表首项 `31317742`，对手 v1、席位 0、`collect-31317742-v1-0-teacher`、step 15 的第一个任务回调。原 Replay 与该局 inputs/labels/index 四个 gzip 共 6,586,966 压缩字节，原哈希及文件 stat 在读取前登记。缺少指定回调或不能在前 256 行 index 中定位时停止，不换种子、回合或样本。达到前缀上限但没有越界只能记无法判定，不能说回调不存在。

先从原 Replay 的有序真实观测重建原冻结完整教师及纯教师 TaskAgent，要求两者都精确复现 Replay 保存的完整动作。不是选种网络与规则任务拼接的混合教师。原单标签、候选顺序与实际训练数值输入必须绑定到这个基线；不能从已排序的缓存观测重建教师并悄悄改变背包顺序。

替代项来自基线首回调的原始候选顺序，排除原标签。每次使用全新观测深拷贝和全新教师实例，仅改变第一个选择，随即恢复原教师并重新生成后续任务与资源预留。最多尝试 64 项，第一次完整动作相同即停。比较按单位编号的 farmer/hands 以及所有有序市场订单；递归保留数组顺序并区分 JSON 值类型。单位动作相同但市场不同单独报告，不算完整动作的正例。

找到替代项只证明该状态、该前缀中存在一个反例，不能把不同分支的替代标签任意组合。只有真正枚举完全部替代项才能报告局部未发现；64 项用完仍有候选则是未完成枚举。候选来自原教师的经营机会生成器，不是官方完整合法动作屏蔽。没有官方转移或后续轨迹，本轮不判断经济收益、模型进步或教师优劣。

整个可执行阶段只运行一次，连续 300 秒：主任务截至第 220 秒，独立核对截至第 270 秒，最终收尾截至第 300 秒。每个关闭阶段的 10 秒包含在原截止内。一个 Windows 所属进程树 worker、单线程数值库、1 GiB 私有提交上限；最多 66 次教师调用，每次最多 10 秒。任务编码与纯教师作物编码分别计数，两者都不是模型前向。禁止 np.load 和模型构造；本轮不读取或校验模型权重，只继承既有身份并检查 stat。

四份原压缩文件各打开一次并完整 SHA 校验。index 只解析目标前缀，inputs/labels 只解析对应的一条；关闭前缀 gzip 后从同一个 raw 计量器继续读取压缩后缀完成哈希，不继续解压/解析。三个前缀的内部未返回解压缓冲保留 planned unknown，失败 unknown 分列。完整 Replay 解码包括其余回合的实际消费；只有合法当前玩家观测进入教师。原始内容和完整请求证据都留在本地。

六个小型内存协议检查与全部数据读取都发生在冻结后的唯一执行中，不创建临时文件。先准备独立核对器，再冻结源码、预算、来源与门槛，完成独立静态预审和精确本地提交，才能首次运行。核对器只读取本轮 case 和主收据各一次，不冒称第二次原始数据或教师执行复现。每个失败保留已开始/完成和未知消费；不重试，不回写旧结果。
