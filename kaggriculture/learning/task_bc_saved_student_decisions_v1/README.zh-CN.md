# 学生实际任务选择历史诊断 V1

研究问题：学生在真实对局中，何时开始偏离同一回调上下文的教师偏好，差别涉及操作、工人还是地块，回合末给该工人的实际请求是什么。只消费已有日志，不运行模型或策略，不重建候选，不改变任何 Bot。

## 事前范围

固定原留出登记首个种子 `1714414373`，`v1 / market / round2` 三对手、双席位的六条 `trained` 轨迹，顺序固定。此种子已消费，现在仅作历史诊断，不是新留出。每局读取完整 step 0–718，含无任务回合，不按收益、预测或错误筛选。

旧元数据记录六条压缩文件共 40,660,889 字节、4,314 回合、12,232 任务回调、575,674 候选、920 条选种记录。每文件哈希一次、gzip 解码一次，原压缩读取合计最多 81,321,778 字节。解压体量未知：总计最多 1 GiB、单文件 256 MiB、单行 8 MiB；超限保存失败并停止，不扩预算或补样。

完整 JSON 解码包括未用于统计的候选 x、shared_x、观测／配置和选种 x／logits，须分别计数，不能将零推理说成零数值输入处理。已消费计数在可能失败的截止／配额／schema 判断之前记录；失败不退款。`uncompressed_bytes` 只计 gzip 返回的 payload；非正常 EOF 退出时，内部尚未返回的缓冲量标为未知。缺失或损坏的终态收据也标为未知，不能把已知下限零写成实际消费零。

## 实现与运行

新提取器只用 Python 标准库。每局输出一个私有逐回调 compact、719 回合计数与来源行哈希收据，以及首个条件分歧或 null。首分歧按原 step 和 record_index 取最早一个，**至多六个**，不要求每局都存在。操作／单位／地块差异可重叠；四标志均保留。聚合报告保留三时段、五教师任务类别的零格、操作混淆和实际请求类别。

独立核对器由另一子代理预先编写，冻结时一并提交；它只单遍读取新 compact，同时校验字节哈希、逐回调身份、零任务回合、首分歧和全部统计，并与旧逐场审计计数比较。它不重读原始轨迹，不冒充独立原始数据复现。每份收据限 2 MiB，见证限 128 KiB，compact 单行限 64 KiB，核对器读取新产物累计限 1 GiB。

执行前先完成 metadata-only prepare、精确源码 freeze、独立预审和本地 Git 提交。该提交不是第三方时间戳。全部可执行检查代码在读取原始轨迹前写好。之后一次执行：6 项微型合成检查及 2 项内存收据失败检查 → 六个逐局提取 → 一个独立核对。合成最多 24 行／48 回调／96 候选／24 选种记录，独立计数。

合成文件放入全新 OS 临时目录，按用户指定使用 `CODEX_HOME` 下经 SHA256 固定的 `skills/agent-workflow/scripts/artifacts.py` 中的独立 `scratch_directory` 工具，只清理本轮所属目录。此调用不启用 Agent Workflow 的任务、路由、钩子或监控。成功只保留回归记录；清理被拒绝则保留原归属标记和本地路径，不重试。

```powershell
.venv/Scripts/python.exe -B -m learning.task_bc_saved_student_decisions_v1.experiment run --out artifacts/task-bc-saved-student-decisions-v1-20261026
```

全程一个 worker、BLAS 单线程，连续 600 秒包含合成、原始哈希与解码、提取、独立核对和进程清理。主工作及其记账最多 450 秒，每局最多 60 秒；独立核对最多 120 秒且工作必须在第 570 秒前结束，最后 30 秒包含其关闭和最终核验。复用既有 Windows Job 控制器，单次 close 仍最多 10 秒，且不延长任一原截止。`summary.json` 单独不代表验收：还须绑定其 SHA 的 `execution-acceptance.json`、进程零退出，以及不存在 `final-deadline-failure.json`。失败即停止新派发，无重试／换样本／隐藏模型兜底。人工源码审查、解释和文档写作在执行钟外，不能追加数据遍历。

## 解释和保留

`teacher_label` 只代表学生当前状态及既有预留下的局部教师偏好，不是完整教师轨迹，也不是另一局同 step 的动作。`unit_request` 是回合末工人的最终请求；它不能证明官方执行结果或某次偏好差造成的利润损失。本轮不读取另一策略轨迹来强行对齐。

只有一个种子，双席／对手／回调相关，不做置信区间、显著性或一般部署错误率推断。最早分歧不是收益下跌的起点；无明确假设时允许“证据不足”。最多提出一个另行登记的后续方向，不自动训练或扩大样本。

模型文件只核继承哈希与当前 stat，不读字节、不加载网络；不声称新鲜模型字节证明。默认源码和官方规则另核原字节。旧结果／失败／审查例外不改，原累计模型评价仍为 3,844 组／226,982 候选。本轮不新增评分、训练、比赛、官方转移或 GPU 工作。原始日志、compact、逐行见证和进程身份仅留本地；公开代码、聚合计数、登记、哈希和审查记录。
