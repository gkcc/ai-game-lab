# 原学生分布锚定的一次受控更新

这是 `task_dagger_once_v1` 之后最后一次同数据、同架构的监督救援对照。
上一轮新开发条件 CE 改善，但原验证 CE 增加 2.516%，未通过 2% 保留门槛；
该失败及未准入结论保持不变。本轮不是继续训练上一轮失败模型。

从原始 S 权重重新开始，冻结选种头、373 维任务编码、候选、控制器和归一化。
唯一学习改动是在原有加权 CE 上加入原学生分布约束：

`CE = sum_256(w * CE) / sum_256(w)`

`KL = sum_old128(w * KL(p_S || p_C)) / sum_old128(w)`

`loss = CE + 1.0 * KL`，温度为 1，参考 S 停止梯度。
每步原训练与聚合训练各抽取 128 组，保留完整候选组和合法性 mask，
PCG64(2026102707)、512 次 Adam、学习率 1e-4、梯度范数裁剪 1。
抽样、优化器和步数不因中间结果改变；只保留最终检查点。
参考网络仅参与训练，部署仍只调用一份任务网络。

保留完整组；不根据预测误差替换样本。最多 100000 行模型呈现另作预留。

新对局种子由 PCG64(2026102718) 取前 10 个合格 uint32，前 2 个开发、后 8 个留出。
排除现存公开文本与本地登记、配置、结果、账本、失败尝试和 job-input 元数据中的已知值，

不声称覆盖已删除、不可访问或外部的全部历史。

## 门槛和停止

1. 已知开发 CE 比率不超过 0.95，原验证不超过 1.02；
   CPU/GPU 比较 atol=1e-4、rtol=1e-5，首 argmax 差异必须为零。
2. 通过后才运行 2 新种子 × 2 冻结对手 × 2 席位 × S/C/T，共 24 场开发。
   C 对 S 的均值自身收益正增益，现金差与比赛得分不退步；每对手自身相对收益至少 -2%、
   得分变化至少 -0.05。C 对 T 整体自身相对收益至少 -2%，每对手得分至少 -0.05。
3. 再通过才运行 8 新种子的 96 场留出。以完整种子聚类、20000 次 bootstrap，
   PCG64(2026102706)，两参考共用抽样。C 对 S 自身增益区间下界大于零、均值相对增益
   至少 0.5%，其余竞争性约束同登记；C 对 T 相对收益区间下界大于 -2%，
   每对手自身至少 -5%、得分至少 -0.05。
   至少 4/32 场 C 留出局须在同一分歧前状态改变真实完整动作。

S 改善、T 保留和实际控制分别判定。任一失败正常关闭本轮，不放宽门槛、重训、
换系数/温度/学习率/步数/混合比例/检查点/种子再试。本轮成功也不自动替换默认 Bot。
不是 PPO，不扩展动作空间，不修改官方规则或已有策略。
