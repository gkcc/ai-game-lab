# 收获候选与最终请求覆盖诊断

本模块是只读元数据消费者，沿用 `task_harvest_window_v1` 的 **240–648** 窗口及完整 719 行校验。它解释旧选择器为何缺少干预点，不修改旧选择器、不补抽新点、不读取模型或运行官方环境。是否读取来源、使用哪些固定来源及资源预算，由另行冻结的运行入口负责；本模块自身不访问文件。

## 接口与证据边界

`analyze(rows, *, side, first_yield_days, guard=None)` 接收单一来源的已认证字典行迭代器。来源认证和官方作物成熟日表的 SHA 校验由调用方负责；成熟日可复用旧选择器的 `first_yield_days_from_source`，不得改用教师常量。返回 `schema_version`、`side`、`window`、`counts`、`examples` 和原样保留的 `original_selection`。`specification()` 给出供事前登记绑定的完整类别、分母和优先级；`empty_counts()` 返回各固定字段为零的新字典。

每行先交旧 `select_target` 完成输入与候选校验，生成器恢复后才计算该行覆盖；读到 EOF 后旧选择器还会检查完整行数。坏尾、资源门槛异常和来源迭代错误都会失败，不返回部分结果或伪装成无命中。整份轨迹还核对每单位、每地块最多一次派工，候选不得重用已占地块、可用单位逐次减少，已预留动作不变，记录中的最终请求与 `final_reservations.unit_actions` 一致。允许 PLANT 已派工但最终产生 PASS 或移动。

这里的“成熟正产量”仅指观测中的 PLANT、正整数产量及达到官方首产日，“原地”指单位回合初始坐标与目标一致；没有添加背包上限、仓容或盈利屏蔽。静态条件和最终请求都**不证明实际执行、收获量、收益或行动优劣**。callback 是计划先后，不是官方单位执行顺序；不能用后续派工信息作为部署模型输入。

## 三层统计

| 层 | 分母及分类 |
| --- | --- |
| callback 漏斗 | 窗口内 callback 数。依次统计 HARVEST、成熟正产量、原地、与原选择同单位、异于原选择；另列原选择已是原地收获、仅其他单位存在原地候选。漏斗列重叠，不能相加。 |
| 候选和地块请求覆盖 | 候选按 `(source,step,unit,target,op)` 去重，地块按 `(source,step,target)` 去重。候选依次分为首见即选择、稍后同单位选择、其他单位最终请求覆盖、无最终收获请求；地块分为首见 callback 请求、稍后请求、无请求。地块分母只含曾出现直接成熟 HARVEST 候选的地块。 |
| 控制器表达范围 | 首 callback 观测中的 `(source,step,unit,current_target)` 原地成熟机会，分为曾表达、首 callback 已预分配且未表达、首 callback 可用但始终未表达。“仅其他单位候选”是两种未表达情况的并列属性，其他单位候选可以需要移动，不代表实际覆盖。 |

`facts` 单列重复候选出现次数、HARVEST 任务最终只移动的派工次数，以及候选地块被移动收获任务或其他任务占用的数量。这些事实可与“无收获请求”重叠，不放进互斥分区。最终 HARVEST 请求必须由站在该地块的单位发出；仅任务名为 HARVEST 而最后动作为移动的记录不算覆盖。

无 callback 的行缺少该回合观测，单列 `unknown_no_callback_window_turns`，不推断为无成熟作物。聚合时不得混用 callback、候选、地块及单位地块数量。即使发现已表达但未请求收获的地块，也只能说明存在值得另行验证的点；不能认定收获会优于继续生产、浇水或其他安排。

`examples` 只保存每个非零计数类别首次出现的本地引用（step、ordinal、unit、target、输入摘要等），不保存整幅输入；引用是首次候选/机会，不一定是稍后覆盖它的派工时刻。来源 ID 由外层绑定。实例与 `original_selection` 中的输入标识留本地，公开投影只选计数和另行审定的说明。

## 合成回归

在项目 `kaggriculture` 目录，使用项目 Python 执行：

```powershell
python -B -m unittest learning.task_harvest_coverage_v1.test_coverage
```

回归保护稍后派工及其他单位覆盖、移动不冒充收获、重复候选去重、表达缺口与预分配、无 callback 的未知状态、坏尾失败、请求及预留不一致。只使用人工字典夹具，不读取私人轨迹，不加载权重，不运行官方状态转移。
