# 联合任务选择示范与接口 V1

本阶段0训练、0新完整比赛。只扩展决策接口，不修改冻结教师、默认Bot、原模型或规则。

`TaskAgent(task_selector=None, crop_mode='teacher')`保留教师选择；传入`task_selector(inputs)`后必须返回现有候选ID。候选是工人＋目标地块＋操作，按单位/坐标/操作固定排序。无效ID直接失败，不回退教师。PLANT的作物选择独立，可传既有检查点SHA与`crop_mode='model'`；本阶段不重训。

输入包含净化后的合法观测、当前实际选择路径的计划资源、275维共享特征及98维每候选特征。计划量不是执行结果。教师分数、优先级、原任务序号、答案和离线种子不作为输入；teacher_label另存。显式背包/仓库键序保留顺序语义。模型可逐候选打分；本阶段不实现网络。

候选仍由原教师的盈利、剩余时间、施肥机会等规则生成，DROP/PICKUP/导航/市场亦保持规则执行。这些限制不能冒称官方合法性屏蔽，接口不覆盖所有机制。新选择会继续原代码的任务删除、工人占用及种子/预计供应更新；后续回调收到实际路径的预留。

原示范是56场collect＋4场collect-smoke：8训练种子48场，2开发验证种子12场。逐719次完整动作对照教师和原Replay，每场官方复演一次共43140旧转移。不是新比赛，也不是当前留出测试。输入/标签/离线索引分别以gzip JSONL保存；同文件组逐行对齐。原作物分类数据不能充当任务标签。

六组固定合成边界各执行原教师与替代选择一次，共12次新官方转移：五类直接效果，加一次替代首选后的种子及占地竞争。构造状态只证明可执行性，不证明自然可达、收益改善或模型能力。预冻结的观测级预检用于核对预期请求，正式单步结果失败后不改状态重试。终局种子可能被市场补购，按单位阶段消耗及成功种植核验。

验收：60场完整动作等价且官方复演一致；五类任务在两分区均有选中示范，且每类都有与其他任务类型竞争时被选的示范；官方控制权、输入隔离与跨局重置通过。公开候选/被选/竞争/种子/不同编码计数，最低结构覆盖不等于数据质量或样本充分。失败保留缺口，不补采、降门槛或自动训练。
