# WSL 空载预热检查

在未来登记新的 GPU 实验前，可从项目目录使用本项目 Python 环境运行：

```text
python -B -m learning.task_wsl_readiness_v1.probe
```

检查先采样 Windows 可用物理内存；不足 5 GiB 时不启动 WSL。达到门槛时，它只启动自己拥有的 WSL 短时空操作，等待该 transport 自然退出并采样内存。运行中若采到低于 4 GiB，或预热最后两秒的采样没有稳定达到 5 GiB，则 `readiness` 为 `false`；采样缺口、超时或回收不能确认时为 `null`。输出不包含本机路径、发行版、账户或具体内存值。

这是为减少一次性训练尝试被 WSL 冷启动内存波动中断而增加的保守预检。它只反映有限采样点和自有 transport 状态，不证明采样间的连续内存、Linux 其他进程的状态、JAX 能否初始化或 GPU 训练有足够内存。若预检通过，未来训练仍须遵守自己事前登记的内存、设备、清理和独立评估门槛。

本命令不读取 seed、模型或 Replay，不启动 GPU、比赛或训练，不关闭整个 WSL，也不终止其他进程。它不会自动重试已失败的实验。发生异常时，如果已拿到自有 transport 句柄，入口会继续等待其自然退出，并保留 `unknown`；不会把事后退出改称检查通过。
