# 一次有限任务数据聚合更新

保留已有独立改善证据的选种头，尝试修复任务头未通过教师能力保留门槛的问题。它是一次 DAgger 式学生状态监督更新，不是强化学习，也不证明分布偏移已经造成历史亏损。

S 为冻结任务网络加冻结选种头；T 为规则任务调度加同一个选种头；C 从 S 的任务权重热启动。三者使用同一候选空间、列顺序、特征、归一化、运输/市场规则和官方引擎。任务网络仍只在原教师经营机会内选择，不能宣称覆盖全部官方动作。

`TaskAgent.select` 在每个实际学生回调中计算当前候选集合的条件教师标签。收集器只将这个标签放入监督目标，不把教师标签、优先分、种子、对手私有信息或未来轨迹作为模型输入。前一次学生决策改变预留资源后，下一个回调重新使用当前上下文；不与独立教师轨迹按序号对齐。标签分歧不等于经济损失或唯一最优动作。

最多 136 场：4 个新训练种子×2 对手×双席位＝16 场收集；2 个新开发种子的 S/C/T 三臂＝24 场；8 个新留出种子的同结构＝96 场。首个训练种子的四场先通过真实官方入口、逐步复演和标签绑定，且至少 128 次教师/学生候选 ID 分歧、覆盖至少两局才继续。门槛仅筛查监督数量，失败不补种子或降低门槛。

新训练标签来自 16 场 S，8 场开发 S 的标签只作固定离线检查。原任务训练缓存只读；每个固定批次128组原训练＋128组新训练，有放回均匀采样。只运行一次 512 步 Adam（学习率1e-4、梯度裁剪1），旧归一化逐位保留，Adam状态重新初始化。只有唯一最终模型，不按开发或留出结果选择检查点。训练候选与每组 mask 完整保留，不截断候选。训练侧float32与部署CPU float64首argmax语义明确区分，导出后核对数值及选择一致性。

使用现有 WSL JAX GPU 环境，实际GPU同步梯度和新权重变化才算训练完成；环境模拟、部署推理和官方复演仍在CPU。旧模型文件、默认Bot和旧失败结论不改。Linux会话监管在正常结束、超时或取消时回收所属进程，不把终止Windows的wsl.exe视为Linux训练已退出。GPU训练工作最多1185秒，预留15秒清理，总1200秒；内层拟合另有600秒训练循环与1200秒硬限时。不满足GPU条件时停止，不悄悄换成CPU处理。

固定离线门槛要求新开发S状态上的条件加权CE至少下降5%，原验证CE不超过旧S的1.02倍；这是工程筛查，不是收益证据。通过后才跑开发C/T。开发收益通过后才启用留出。留出按8个完整种子聚类，20,000次固定PCG64 bootstrap。C对S自身净收益差95%区间下限须>0，增量至少为S均值0.5%，总体现金差与得分不退步，每对手自身收益和得分另设保护；C对T的总体相对净收益95%区间下限须>−2%，每对手收益和得分另设保护。至少4个C留出局须在与S相同的分歧前状态上产生不同完整请求。对S改善、对T保留及动作控制证据分别报告，通过也不替换默认Bot。

官方实战与主要复演各最多97,784步；独立样本最多4场、2,876步，总198,444步。独立预选首训练种子round2席0的S、首开发种子round2席0的C、首留出种子market席0的C与T；未到阶段不替换。全部比赛需720状态/719动作/双方DONE，并逐步验证公开/私有状态、背包顺序、双方动作、请求追踪、实际执行和现金奖励。计算预算包含未完成及在途任务，训练与离线评分另按实际候选行和padding分别计数。
