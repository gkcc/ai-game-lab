# 两臂训练和开发评估的内存闭环

`train_and_export` 接收调用方已认证的训练 mapping、检查点和 schema、类别权重与显式设备，复用现有共享批次两臂训练、设备到主机桥及内存导出器；返回私有基线快照和两份检查点字节。它在外部回调前复制基线，以免之后更改原模型影响导出。测试只允许合成数据、显式 CPU 和 2×8 预算，至少一次独立辅助梯度非零；生产形状分支要求 64×256、显式 GPU 且至少 32 次独立辅助梯度非零，不达门槛不会导出。此函数不认证真实来源、GPU 型号或登记。

`models_from_memory` 仅供内存闭环：它解码刚生成的字节并构造 `TaskNetwork` 评分对象，并未调用 `TaskNetwork(path, sha)`。`evaluate_models` 单独接收三个调用方提供的 `TaskNetwork`，所以未来入口可以传真实磁盘重载的对象；它复用逐组 scorer 和已有评估器，对 teacher_dev、conditional_old、conditional_new 分别计算 all 与未重合子集。模型及掩码在回调前各自快照，返回指标仅供本机使用。调用方必须保证视图、模型和数据在调用期间的身份及不可变性；快照不是并发锁。

正式入口须事先认证数据、模型、schema、私有掩码和角色顺序，固定唯一尝试、64 步及 RTX 身份并监管进程；排他写入新文件后必须调用原 `TaskNetwork` 从磁盘重载，逐组比较 logits、首位 argmax 和近似平分。合成内存重载不证明真实文件入口、真实 GPU 训练或模型竞技提升；已使用的开发数据及其未重合子集不是独立对局。
