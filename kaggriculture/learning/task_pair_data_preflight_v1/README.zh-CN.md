# 两臂任务 BC：已有示范的数据准备

为后续比较“完整候选交叉熵”与“同一损失加同目标工人排序辅助项”，本阶段只检查并整理已有示范；不加载检查点权重、不进行模型推理或训练、不新增比赛，也不更改默认 Bot、冻结模型、官方规则或历史证据。后续两个候选须另行冻结相同初始化、归一化、批次与训练预算；本阶段没有训练结果。

固定原教师缓存的 8 个训练簇（108,310 个决策组）、2 个已消费开发簇（27,096 组），以及两份条件教师档案的 4 个已消费开发簇（5,104 组）。三种角色按完整种子簇互斥；对外不公开种子值。两个开发池都已参与历史开发，部分条件教师状态由早期模型参与生成，不能称为独立留出。原教师是规则作物路径上的实际教师选择；条件来源包括混合路径下的条件教师标签。特征 schema 一致并不意味着两种状态分布相同，也不证明任务实际执行。

原缓存按历史清单对 16 个 NPY 文件逐块计算 SHA，随后以只读内存映射加载并核对形状、dtype、偏移和教师标签；不把约 2.9 GB 缓存转成 Python 组列表。条件来源继续使用现有认证 NPZ 读取器；NPZ 会先读取快照再解码，不具备同样的按需映射。对全部分组核验有限数值、候选数值身份和顺序、距离、操作编码和教师标签，并将原缓存的数值身份与其独立身份数组核对；每组最多 256 个候选，不截断组。本阶段不重新读取原始观测，不能独立证明单位真实存在、动作官方可执行或候选覆盖官方完整动作空间，机会集仍受教师经济门控。角色标签、单位/目标身份校验信息和生成的掩码不额外输入模型；单位/目标本身仍属于原有合法观测特征。

数值重合采用既有 NumericEquivalence 口径：组宽、275 个共享 float32 和完整有序候选 float32；带符号零规范化。只为两个开发来源建立组摘要索引，流式扫描训练组；摘要命中还逐块比较真实数值及组内标签。开发组区分未重合、重合同标签、出现任何不同标签；冲突不被静默删去。比较的是模型数值输入投影，不证明完整游戏状态、对局或未来分布相同；不统计两个开发池彼此之间的重合。原训练/验证的重合须复现历史上公开的 3,978 个验证决策组、零跨分区标签冲突；历史非零冲突按不同数值组计，本预检按验证决策组计，只比较零与非零。结果不一致即停止，不覆盖原历史结论。

预先固定目标资格：训练来源中教师选择 `PLANT`、同目标至少两个不同单位的组不少于 20 个且来自至少两个训练簇；原教师开发池及条件教师四簇整体各自的此类组合计不少于 20，且各簇均不少于 5 组。条件教师的旧、新两份档案还各自单独应用同一门槛，不能用合并后的支持度掩盖某份来源不足。每个来源、每种教师选中操作至少 20 组且覆盖至少两个簇才标为 `supported`，否则为 `unknown`；未知不算通过。分别对全部开发组和未与训练数值输入重合的开发组检查支持情况。资格只是决定哪些开发指标可评价，不代表独立样本量、胜率或收益。若发现相同数值输入存在不同教师标签，标记 `detected` 并停止将数据称为准备就绪，不能自动过滤或调整门槛。

本机私有产物包括每个开发分片的 `seen_in_train`、`label_conflict` 和 `qualifying_plant` 布尔掩码及其身份清单；清单绑定登记提交和条件来源的旧／新顺序。它们只用于后续分层，不作为模型输入，不上传。公开投影仅给支持/未知、重合是否达到 20 组的粗阈值、是否发现标签冲突，以及分别针对全部组和未重合子集的主要 `PLANT` 指标准备状态；不公开种子、单簇计数、逐组掩码、原始特征或完整档案。全部组准备状态不能代替未重合子集准备状态，也不能把其他操作的 `unknown` 当成通过。标签冲突存在性是明确披露的一个整体布尔结果；粗阈值不提供形式化匿名保证。

未来读取掩码时，必须由登记提交逐级核对来源清单、数组身份和分片顺序，再检查本地掩码摘要与长度；仅凭掩码长度相同不能认定它对应当前数组。本地清单本身不直接保存原始数据摘要。

开始时采样可用内存至少 4 GiB，运行中每 256 次检查采样可用内存至少 2 GiB，采样截止 900 秒；均不是硬实时或内存上限。大文件摘要按块读取，NPZ 快照与中间数组仍有额外内存成本。结果先写本机独立目录，掩码读回后才发布粗结果；应同时检查进程退出码和完整结果。源码、登记和默认 Bot 前后校验不是操作系统锁，缓存摘要只在读取前流式核验，不能排除同用户并发替换。失败留证、不自动重试、补数据或放宽门槛。

使用前须完成独立审查并提交事前登记；本地提交不是第三方时间戳。仓库根目录下将占位符替换成本机路径和登记提交：

```text
python -B -I kaggriculture/learning/task_pair_data_preflight_v1/run.py --game-root <本机游戏项目根> --output-dir <项目根下的artifacts/task-pair-data-preflight-v1-20261030> --registration-commit <登记提交完整SHA>
```
