# 整回合教师请求收益选择器 V1

本实验保留原学生和全部旧结果。上一轮 raw top2 的32候选变化只有10次改变完整请求，训练信号不足；本轮不重判旧门槛，而在新种子中直接比较同一观测上的完整请求。

S为两个冻结网络组成的学生。T为 `TaskAgent(None,'model',同一选种网络)`：规则任务调度加同一选种网络，不是原始全规则教师。双方独立生成完整 farmer、hands、有序 market；一回合只选择其中一个完整对象，不混合字段。候选排序、神经权重、官方规则与默认Bot不改。

训练/开发每局提前分配一个40回合窗口（80–119、260–299、440–479，按种子序号、对手序号和席位求模）。从窗口首回合顺序检查，首个S/T完整请求确实不同的时刻是唯一介入机会；没有差异就保留缺失单元，不补种子。A整局用S，B仅此回合用T，随后恢复S。必须同初始状态、同干预前轨迹，真实请求不同。选择机会不读取终局结果或未来状态。

标签改为双方终局现金差的配对增量除以1000。自身利润、对手利润、比赛得分仍分别报告。八项输入为可见回合、S任务数量、T减S的五类已选任务数量、T减S的已选任务距离总和；这些是提案特征而非执行事实。各控制器独立汇总自身记录，不按分歧后的回调序号对齐，不读取教师优先分、标签或对手私有信息。

只拟合一次CPU float64 ridge：8特征加截距，训练集均值/标准差（下限1），平均平方误差加非截距权重平方和。零与负标签保留，不要求人为凑出正负配额。模型导出后固定SHA，所有开发预测、部署、重载与审计均绑定同一身份。

最多176场：训练8种子×2对手×2席位×2分支=64；开发2种子同结构=16；留出8种子×2对手×2席位×3策略=96。第三臂是在所有回合使用T，另两臂为S和学习选择器。留出选择器每个窗口只消费首个完整请求分歧，预测现金差增量大于零才选T，每局最多三次；一次介入的标签不被解释为可相加的多次收益。

前两个训练种子完成后，若少于四个有效分歧配对，或所有观察到的现金差增量都为零，立即关闭本分支；不会先派发第三种子。完整训练门槛为至少24个有效配对、12个非零现金差标签且覆盖六个种子。开发必须在两个种子上有非零信号，且所学选择的平均现金差严格超过“始终选S”和“只在机会回合始终选T”两种常量选择，并守住自身利润和比赛得分限制。失败不调参、不另采样。

留出使用八个完整种子聚类、20,000次固定PCG64 bootstrap（种子2026102704，linear分位数）。学生改善要求配对现金差均值的95%区间下限大于零，以及各对手利润/得分和实际动作变化保护。教师能力保持与教师优势分开判定；所有利润比例重新计算分母，点估计及每次重采样分母均须为正。具体门槛见登记与statistics.py。成功也不自动替换默认Bot。

实战和主要官方复演各最多126,544步；独立抽样最多四场、2,876步，总255,964步。所有实际提案、双方控制器、重载、原控制器一致性检查和主要复演推理都计入预算；不能把未提交给引擎的T提案当成免费计算。派发前按全部已派发（含尚在运行）任务的单局上界预留资源。任务网络前向上限1,200,000，选种3,000,000，神经输入60,000,000行，完整控制器/对手计算600,000次，门控预测1,000次。T臂没有任务网络调用。这里没有GPU训练或PPO。

最多两个比赛进程，机器阶段10,800秒、每场含主要复演900秒、拟合60秒。每场真实官方入口必须完整720状态、719动作、双方DONE；逐步保序复演并重建实际请求和全部提案追踪。初始两席学生基线核对旧JointAgent全局一致；若进入留出，第一场T臂核对旧TaskAgent全局一致。独立复演预选首个训练种子的round2席位0两分支，以及首个留出种子的market席位0学习/T两臂；未到达的单元不替换。
