# 固定任务学生的分层历史错误诊断 V1

目标是查明固定任务学生在所选旧教师示范中，哪些任务类型和时段出现候选、操作、工人或地块选择分歧。保留模型、默认 Bot、官方规则和旧比赛结论。本轮不训练、不调用完整策略、不运行比赛或官方状态转移。

## 固定选择与解释范围

原八个训练种子、两个验证种子分别保留旧登记顺序。第 i 个种子、席位 b 使用 `[v1, market, round2][(i+b)%3]`，从旧账本解析真实游戏身份，得到 20 份示范，按原 source manifest 顺序读取。

每份示范划分为 0–239、240–479、480–718 三个时段，并按 DIG、FERTILIZE、HARVEST、PLANT、WATER 五个教师标签分格。每格选择 canonical JSON `[task-bc-stratified-error-sample-v1, game, source_row_index]` 哈希最小的至多两行，哈希相同时按原行号。不按预测、错误、回报或数值去重选样；空格保留，不能补样。

最大 600 条（训练 480、验证 120）、60,000 候选。保留原物理行号及 step/decision，允许稀疏记录的合法间隔，不改造成前缀或连续编号。先固定整份样本，再调用模型。

这是已知历史数据的条件诊断。分层改变原频率，所选调用和数值 unique 的统计均不能代表完整分布；样本训练支持未命中不代表完整训练集没有覆盖，更不能直接解释比赛现金损失。缺类、重复过高、没有清晰分歧均可如实报告证据不足。

## 一次执行与预算

```powershell
.venv/Scripts/python.exe -B -m learning.task_bc_stratified_error_sample_v1.runner run --out artifacts/task-bc-stratified-error-sample-v1-20261025
```

先完成 metadata-only `prepare`、源码 `freeze`、精确独立预审及本地事前 Git 提交，再写 `pre-execution-commit.json`。以上不是第三方时间戳。该入口拒绝已开始的运行；错误后不能恢复、补跑或延长时限。

顺序为小型合成回归、20 次逐游戏采样、样本冻结、一次纯函数参考、完整训练支持索引、20 个评分分片、汇总、精确比较、报告。共 47 个外层任务，一个 worker、BLAS 单线程。每次工作最多 120 秒，并在 900 秒连续总预算中预留同一次 10 秒清理窗口；正常根进程退出后的 2 秒等待仍受原截止约束。复用已验收的 Windows Job 控制器，不重跑其七项生命周期矩阵。

60 个原始 gzip 文件各哈希一次、扫描一次：45,121 组原始对齐记录，三流总计 135,363 物理行。index/label 全部解析，inputs 只解析入选的至多 600 行。跳过的物理行、实际解压字节和压缩文件哈希读取均有计数。每行 JSON 上限 16 MiB，原候选数上限 242；最终入选候选超过 60,000 时评分前停止，不截断或换样本。

参考与分片两遍合计新增最多 1,200 次样本评价／120,000 候选，缓存命中也计费。承接旧 2,816／162,250，累计最多 4,016／282,250，失败预留不退款。派生样本解析另限 2,160 行／240,000 候选；报告和独立复核消费已保存 compact，不再读取数值输入或调用模型。合成回归另限 12 项、64 次数值输入处理／256 候选；回读及失败解析计入，fixture 构造和 metadata 操作单独披露。

## 输出与保留

样本、稀疏 manifest、局部进程身份、错误日志、支持索引、每行 compact 和至多五个首个分歧见证只保存在新本地结果目录。公开内容限源码、相对来源哈希、预算、覆盖与聚合条件统计、审查及中文结论。见证依据已有评分记录，不能据其宣称重演了反事实利润。

历史保护分三层：继承原保护字典及证书；当前源码、模型、规则、metadata 和上一退出阶段派生产物重新哈希（派生 compact/pickle/logs 只哈希、不解码）；其他旧大文件只核 before/after stat。选中 60 个原流在实际采样预算内校验哈希一次。不会为了历史审计再次读取未授权原始数据，也不会把 stat 记录写成新鲜的全量字节证明。

合成失败、来源/身份不一致、预算或资源超限、评分路径不一致、退出回收失败均停止后续派发。执行完整性与诊断信息量分别评价；旧容量失败、旧完整诊断失败、旧学生比赛准入失败均保留，不因本轮局部正确而追认通过。
