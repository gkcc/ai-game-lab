# 固定双头学生：新种子经营能力保留评估

不训练、不改参数、不重选模型。任务网络与改进选种头固定，对照是规则任务＋同一个选种头的混合参考，不是原始全规则教师。候选经营机会、运输和市场仍来自冻结控制器；本阶段不证明完整动作空间学习。

显式 `seeds.json` 是 Python `Random(2026102340).sample(range(2**32),8)` 的一次无放回抽样。准备入口检查当前公开文本、本地注册/清单/账本/结果/配置/种子文件及失败派发记录，任何历史碰撞直接停止，不自动重抽。未运行的预留种子也排除；检查范围不包含其他机器或已删除且未留记录的实验，不能宣称全世界首次使用。

8种子×3冻结对手（v1、market、round2）×双席位×两臂＝96场。全部经过真实官方文件入口，最多两个独立进程；官方模拟和模型状态不在线程间共享。按登记种子顺序，每个种子依次对手、臂、席位，不提前派发下一种子。每个比赛＋审计进程最多900秒，失败停止新派发，收尾已在途任务，不重试或替换。每完整种子检查学生平均终局现金是否低于参考50%；触发即安全停止，不对截短面板做确认性推断。

净收益读取真实Replay初始和终局现金之差；48个同种子/对手/席位配对。主要相对差为平均配对增量÷参考平均净收益，不是逐场百分比平均。PCG64(2026102341)抽取20,000份8种子整簇样本，每簇保留全部6对配对，每次重新算分子和分母，用linear分位数报告双侧95%区间。总体、逐对手及各自实际bootstrap参考分母须为正，否则相应相对指标不定义、不能准入。逐种子、逐配对的描述性分母非正时只标null，不额外设门槛。

主要门槛：相对差区间下限严格大于−2%；每对手观察均值净收益相对差不低于−5%、比赛得分差不低于−0.05；并通过全部执行、身份、隔离、复演和历史保护检查。2%是提前声明的工程容忍度，不是自然游戏阈值。分组点估计保护不是统计非劣证明。8簇仍很少，20,000次重采样不增加信息量；仅主要区间下限>0才可描述此面板净收益提升，不能自动推广为超越教师。
