# 两臂任务头：内存检查点快照组件

本组件只处理调用方提供的内存字节和数组，不读取文件、真实模型或训练数据，不训练、使用 GPU 或运行比赛。正式入口尚未实现；当前合成测试不能作为训练或真实部署验收。

`load_checkpoint` 要求传入不可变 NPZ 字节、**事先独立固定**的模型 SHA256 和部署可观测特征 schema SHA256；只计算这一个快照的身份，不在哈希后重读文件。ZIP 总字节最多 2 MiB，成员展开总字节最多 1 MiB；只接受预期九个不同的 NPY 成员，并限制压缩方式、头大小及 metadata 大小。所有 NPY 头的形状、dtype 和精确负载大小均通过后才解码数组。模型参数必须是有限的 float32，并匹配现有任务头的生产维度；归一化数组必须有限、尺度不小于 1，非连续特征的均值和尺度分别为 0 和 1。返回的权重和归一化数组默认只读，不应打印或上传。

必要的 schema、维度、操作类别和归一化约束显式核对，并复用现有 `task_bc_v1.model` 的 `DIMENSIONS`、`OPS`、`schema_hash` 与 `continuous_mask`。这是对当前 `TaskNetwork` 语义的实现，并非实际调用其路径构造器。schema SHA 必须由已认证的部署可观测特征来源提供，不能从待验证模型自行选择；本组件不生成模型输入，也不能仅凭特征名或哈希证明调用方没有另行输入教师标签、对手私有信息或对局种子。

导出必须原样保留已绑定的 schema 字符串以维持模型兼容；如果其中本身含有路径、种子标记或其他敏感信息，这些字符串也会保留在本地权重文件中。本组件不自动脱敏 schema，未来调用方必须独立审查并绑定每个特征名，权重继续按私有产物处理，不能声称导出已完成全面脱敏。

`export_pair` 只返回控制臂和辅助臂各自独立的 NPZ 字节；两臂参数须彼此不同且与基线不同。它原样保留基线均值和尺度，保留现有 scorer 需要的 schema 字段，其他旧模型 metadata 一律不复制；只增加受限枚举的臂、训练来源、初始化、登记提交、完成步数和损失系数，不接收自由文本路径或种子。真实来源必须声明完成 64 步，合成来源明确标为 synthetic。此处仅校验调用方给出的受限声明，不能单凭 metadata 证明训练真的发生。

真实阶段须先冻结并验证模型及 schema 来源、训练证据和输出目录，分别排他写入新文件，然后**实际使用未经修改的 `TaskNetwork` 从磁盘重载**并核对 logits、选序与身份；不能把本模块的内存语义测试冒充真实文件入口验收。源码、模型身份核对也不是文件锁，并发替换风险须由正式入口说明。
