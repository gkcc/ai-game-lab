# 已消费条件分歧：完整配对探索

本登记仅允许对已封存单步预筛中的全部合格候选进行一次完整配对，不按收益选择、替换或补充候选。候选真实数量和身份、固定顺序、种子、观测摘要、候选 ID、模型身份与两方逐场结果仅保存在本机；以独立 256 位随机盐计算的绑定摘要公开。公开仅写候选数在 4 至 8 之间、比赛和官方复演各不超过 16 场，不公开可反推具体数量或逐坐标结果的细分账目。

固定来源是已经完成并封存的旧预筛，读取的同一份私有计划及汇总字节必须与旧完成收据摘要一致，再校验旧登记、代码、规则、模型及案例结构。按旧计划顺序绑定每个角色、对手、席位、窗口、排名、step、ordinal、已消费种子、双方候选 ID、输入摘要及模型身份；不得读取未消费种子清单。登记源码、规则/core、Python 和依赖版本；项目默认 Bot 的本机字节身份存于私有绑定并在运行前后核对。

每个案例先从初始状态运行控制局，逐帧核对历史 720 状态、719 次双方请求、单位背包与仓库顺序及稳定 trace；本轮只规范化既有 crop 推理计时字段。每场 trace 完整扫描两遍：先校验身份、标签和计数连续，再用既有验证器逐行核查全局及每回合模型预算。为减少内存，第二遍在单线程子进程中临时关闭该验证器的采样行保留，异常时也恢复原设置，预算断言仍执行。控制局完成并经独立受管官方复演以及完整历史对齐验收后，才允许启动该案例的干预局。干预局从初始状态启动，目标动作前对齐控制局状态及双方请求，并在目标同回合核对对手请求；目标处先照常运行并计费一次冻结学生模型，只在完整有序单方输入、原学生选择、动态教师标签及预算均匹配时替换一次候选 ID。目标回合完成前核验，其他选择仍由学生和冻结对手现场决定。模型不得读取种子、Replay info、对手私有状态、候选标签或未来轨迹。

记录目标请求与 canonical/Python 非动作下一帧的实际变化；每局另由受管子进程以原官方引擎复演 719 次转移，验证 v2、背包顺序并补查双方 720 帧仓库顺序。官方 replay 的 canonical 比较与 Python 对类型和普通字典顺序的等值存在局限；v2 摘要与额外仓库顺序检查的覆盖范围应分别报告，不声称原始字节一致。任何来源、前缀、目标、回放、身份、资源或清理校验失败立即停止，不重试、不换候选；有异常的配对不能参与收益判断。

各案例按 `prepare_case → control → control_audit → control_verify → intervene → intervene_audit → pair_verify` 固定顺序串行，每个单元由独立的 Windows Job 执行并回收；控制复演和完整对齐均通过后才能启动干预。最多 16 场官方比赛和 16 次官方复演，即 23,008 次动作转移，不自动增加复演。启动和阶段间可用物理内存至少 5 GiB，运行期至少 4 GiB；Job 的 RSS/commit 上限分别为 2/3 GiB，每单元最多 900 秒，总截止 8 小时。磁盘预留 4 GiB，私有产物总预算 8 GiB；每次准备最多 8 MiB、每局最多 160 MiB、各复演或验证最多 1 MiB，均从剩余额度计费，失败不退款。

输出预算使用既有 `owned_writes` 拦截该 Job 内的 Python 写入。为兼容受控 Git 子进程的 DEVNULL，作用域中仅对事前核实的 Windows `nul` 设备及精确 `O_RDWR` 放行，其他可写 `os.open` 仍拒绝；异常也恢复守卫。它不是文件系统硬配额，原生直接写入、预先打开的描述符和其他进程不受其保证。空闲磁盘、Job 资源和自身目录大小按阶段及协作式 guard 检查，不是硬实时保证。进程被强制终止导致无法取得完整写入收据时记为未知并停止，不声称精确消耗。

仅全部技术验收通过后计算描述性信号：配对平均自身净现金增量严格大于零，且双方现金差增量和得分增量均不小于零。本机另按已消费角色保存各指标的描述性均值，不公开各簇数值、不另设分组门槛。仅有两个已消费种子簇，且案例经单步变化筛选；不将案例当独立种子，不声称统计显著、泛化或模型晋级。相同初始种子不保证之后随机事件相同：日终空地状态会改变随机数消耗及另一方和城镇结果。收益差包含双方后续策略、共享市场与官方状态相关随机流的共同影响。

无训练、GPU 训练、PPO、新种子、线上提交或默认 Bot 变更。原始 Replay、trace、日志、私有计划与逐场账目留在本机；公开只发布审查过的粗粒度结论。

游戏阶段在解析参数后清空进程内 `sys.argv`，避免把种子暴露给 Agent；因此本机比赛结果中的 `command` 不构成完整复现命令。真实复现参数以本机带盐认证的私有绑定为准，公开入口不含种子。
