# 固定第6步选种模型的独立留出验收

只检验原学生与固定第6步模型，不训练、不改策略、不重选已看过的21个头，不改变默认模型。上一轮4开发种子的探索通过是本次准入依据；旧全批次训练实验仍为离线失败、0比赛。本次不追认或校准原50%错误削减门槛。

在新结果产生前冻结8个未见种子、两检查点、3个对手、规则、源码、统计与门槛，独立预审后本地提交，再运行8×3×2席位×2模型=96场；2场预指定文件入口复现另计，不进入统计。种子新颖性限于扫描的现存公开文本与本地JSON证据，不是全球未使用证明。本地Git登记不是第三方时间戳。

主比较为相同种子/对手/席位的第6步减原学生。每个完整种子保留3对手与双席位，得到8个独立统计簇；固定随机数进行20,000次整种子重采样，以线性分位数计算平均净收益增量的双侧95%百分位区间。重采样次数不会增加独立样本量。

研究用改进学生基线门槛：自身平均净收益增量的区间下限>0，点估计增量至少为本次原学生平均净收益的1%（基线必须为正）；总体现金差、比赛得分增量≥0；市场对手组自身收益、现金差、得分增量均≥0；全部执行、历史保护、复演和隐私检查通过。后两组是点估计保护条件，不宣称总体统计非劣。即使通过也不替换默认Bot、不宣称超越教师或具备完整游戏机制学习。

公开全部48配对、8种子、3对手、两模型胜平负，以及逐个删除种子后的7种子均值。后者只描述稳健性，不用于换头、追加测试或调整验收条件。失败保留研究候选，不重新使用同一留出集调参后补考。

运行入口：`python -B -m learning.bc_epoch6_holdout_v1.experiment MODE --out artifacts/bc-epoch6-holdout-v1-20261023`，`prepare`另需`--public`。准备、比赛和分析用learning虚拟环境；`audit`及官方文件入口使用游戏虚拟环境。顺序为prepare、独立预审、本地提交与收据、games、entries、audit、analyze。启动标记和失败收据阻止自动重复比赛。

复用既有官方Worker、模型入口、控制审计、执行追踪与经济消费者。新audit明确接受`holdout`及`entry`，不把留出结果伪装成旧development输入；不调用旧四种子统计器。每场两次官方复演核对双方动作与稳定轨迹、公开/私有状态、背包顺序、v1/v2、终局现金奖励和实际成交账目。原始回放、权重、轨迹和日志只保存在本机，公开脱敏账本与哈希。
