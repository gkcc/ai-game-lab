# 开发集评估适配：合成阶段

这里把调用方已经认证的一个开发来源接到已有 `evaluation.evaluate`。`feature_blocks` 按完整候选组给出原顺序的共享特征、候选特征和分组边界；模型只应收到前两种特征，不把教师标签、簇、掩码、组索引或边界数值拼入特征。接口本身不运行模型，也不能证明调用方未将其他信息传给模型。schema 摘要必须来自独立认证的固定来源。

`evaluate_source` 接受按原组顺序连续覆盖的 `LogitBlock`。每块必须提供所有真实候选的有限 float32／float64 logits；可选的组内选择必须覆盖每块并等于第一个最大值。只有最终选择时无法恢复同目标内工人排名，因此不能用选择伪造 logits。实现先限制组数、候选数和每块尺寸，最多暂存 200 万个 float64 logits；再分别调用现有评估器计算 `all` 与 `unseen_train`，不平均各块结果。两者都使用该来源事先固定的完整预期簇；缺簇或支持不足时现有评估器返回 `unknown`。

一次调用只接受 `teacher_dev`、`conditional_old` 或 `conditional_new` 中的一个，旧／新分片分别报告，不合并为一个结果。来源标签、长度和簇集合不能证明分片身份或顺序；调用方必须独立认证原始登记、逐行来源、数据、模型、推理方式、掩码绑定、预期簇和 old/new 顺序，并保证使用期间不可变。只读数组视图不是锁。现有开发数据已经被使用，未重合集不等于独立比赛或新留出测试。精确结果仅供本机使用，发表前需另做隐私审查。
