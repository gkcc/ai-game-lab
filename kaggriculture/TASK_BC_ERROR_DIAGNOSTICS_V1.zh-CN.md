## 执行边界与历史保护

Windows 虚拟环境启动器在本机还会生成实际 Python 子解释器。原运行器的 `kill/wait` 与模拟回归只证明直接子进程回收，不足以证明所有后代总能回收。本次子解释器主动触发截止错误，主代理和独立复核员分别现场核对了四个已观察的启动器/解释器身份，均已不存在，没有额外杀进程。本次无残留的实测事实不能扩写成通用进程树终止保证；后续运行前应补真实 Windows 路径的针对性保障。

原 4,822 个运行文件、739 个公开文件在本阶段终态核验时均保持原字节；96 个冻结运行源码和 386 个输入哈希通过。公开交付只会对两个 review 入口追加新说明，不覆盖历史证书、负结果或冻结文件。原始 Replay、逐步轨迹、模型、日志、进程身份和私有观测继续留在本地。

独立审查通过只表示失败与停止证据可靠，不表示本轮诊断成功，更不表示模型晋级。预审第一次发现的覆盖漏洞及负审回执也已保留，冻结前修复不覆盖首次事实。
