# 合并教师示范的有限 BC：事前登记

上一次加权任务模型在三种子对照中未通过探索护栏。新示范增加了开垦与施肥选择，但只来自两个开发种子，不能证明策略更强。本阶段将旧教师示范与新示范按旧在前的顺序合并，沿用原任务选择网络、初始化种子、未额外赋类别权重的训练器及 128 次更新；不根据已消费比赛的收益继续调参。

冻结的两份输入分别为 2,253 和 2,851 组，共 5,104 组、322,151 行候选。旧数据原有固定比例抽样；新数据保留所有开垦、施肥选择，其他选择按固定比例抽样。因此合并数据并非自然分布，原训练器每次随机排列后还会按候选宽度、padding 预算与每批最多 256 组筛选，不能把实际入批概率说成简单均匀或推断类别曝光。

历史公开证书和本地文件的 SHA、相同 schema、已登记组数及种子角色必须通过接纳检查。可识别的历史测试、留出、验证和预留 seed 保守排除；只有四份与公开原件及旧训练来源严格绑定的开发观察登记例外。完整本地角色清单只以数量和 SHA 进入公开登记，缺失、私有、外部或未识别的历史仍不能排除。

每份私有档案由受控 Linux worker 各做一次有界数值解码快照；事前及执行中的准入校验可能多次流式读取文件计算哈希，因此不能宣称文件只读一次。合并和转换可能同时产生多份数组；主机采样门槛与输入大小限制不是硬实时 RAM 或 GPU 显存上限。Windows 监督 transport，Linux guard 负责其受控 session 的退出与清理，两侧收据均须通过。

若冻结身份和资源满足条件，只启动一次小规模 JAX GPU fit；实际设备须与经哈希绑定的本地私有配置精确一致，还要求 128 次同步更新、非零梯度、参数变化和 16 组同步 CPU／GPU 推理对照。对照使用合并数组最前面的旧数据组，不能因此证明覆盖新示范的全部类别。预检后、单次开始标记前再次核验身份；标记产生后任何资源、身份、数值、时间或清理失败均停止，不重试或替换输入。

原模型、默认 Bot、冻结教师及官方引擎保持不变；新 checkpoint 与训练数据只留在本地。此阶段不跑新比赛、不做 PPO、不自动晋级；技术训练通过也不说明竞技收益提高。后续官方对照须另行冻结未参与开发的测试方案，公开或已消费种子不能自动称为独立留出。

独立子代理完成事前预审；它不是 WebChat，也没有读取数组、启动 WSL/GPU 或验证真实训练。事前提交仅证明本地版本关系，不是独立第三方时间戳；真实 GPU 使用、清理及结果须以运行收据为准。

发布前检查拦截了不必要的设备型号；本地保留原冻结和审查文件，公开历史哈希，并将型号保留在哈希绑定的私有设备配置中。实际训练仍需对设备名称和类型做精确匹配。

集成检查发现新 checkpoint 的父目录此前不会被创建，现由宿主在单次开始标记前准备并验证为空，worker 在训练前再次验证；已有文件、外部链接或意外目录内容不会被删除或覆盖。原训练器的独占创建保护保持不变。检查间隙仍存在普通文件系统时序窗口，不作为抵御同权限恶意替换的安全边界。

## 实际结果：有限训练通过，实战效果未评估

事前提交 `d8a1c2ff025991f724ee1ca5220aac4b27f277a4`。worker 使用与私有配置精确匹配的 GPU，报告完成 **128 次同步更新、128 次非零梯度更新**，参数相对初始化发生变化。固定 16 组、1,128 行候选的 CPU／GPU 推理对照通过，最大绝对误差约为 `1.254e-6`；请求了最高矩阵精度，但未单独测量硬件实际精度。这 16 组均取自旧数据开头，不能当作新示范所有类别的验证。

主机记录 350 次内存采样，Windows transport 和 Linux session 收据均报告清理完成。独立子代理及主代理核对了冻结源码、收据链、128 次更新与 16 次对照的进度计数和 checkpoint 字节哈希；没有独立重算梯度或 logits，也没有实时监测设备。内存采样不是系统 RAM 或 GPU 显存硬上限。

新 checkpoint 仅保存在本地，大小 215,030 字节；既有模型和默认 Bot 的哈希未变。本阶段没有新比赛，没有自动替换模型或晋级，亦未证明收益改善。GPU 用于本次网络训练和对照，官方游戏仿真仍由 CPU 执行。

公开证据含训练结果、清理收据、汇总和哈希；原始进度日志、模型、训练数组及设备配置留在本地。开始标记投影省略了临时令牌哈希，因而公开投影不能单独重算原始标记哈希；本地原件用于独立复审。后续需单独冻结未参与开发的官方对局与统计方案，才能评估该候选的实战表现。
