# 训练样本内的学生与教师选择偏差

新模型在两个全新种子的对照中未通过事前非退化护栏。为避免将已消费的留出结果变成反复调参依据，本实验只检查此前已消费的训练数据，不读取两枚新留出种子的回放或 trace，不重新训练或进行比赛。

先冻结训练缓存、新旧两个任务模型、源码及依赖的身份。从已有 2253 组训练样本中，按固定域字符串和组索引的 SHA256 排序选前 200 组，不参考标签、模型得分或比赛结果。每组使用相同候选与教师标签，按新模型、旧模型的固定顺序各做一次 NumPy CPU 前向，总计最多 400 次；两模型累计候选行不超过 120000。缓存只读取一次不可变快照，限制归档读取和解码大小；先确认标签、数值、候选及总预算有效，再进行预测。

输出只包括两个模型对教师选择的 top-1 一致率、教师选项在模型排序中的名次、按教师动作类别的聚合数量和配对的都一致／仅新一致／仅旧一致／都不一致次数。同分按原候选顺序，与实际 `argmax` 行为一致；类别无样本时比例为未知。新模型训练时见过这些样本，旧模型未必见过；条件教师标签来自混合控制器访问的状态。结果不能证明泛化能力、比赛收益因果或模型应当晋级。

事前提交后，首先在单次受限的自有命名 Windows Job 中运行不读取训练输入的合成成员探针；验证解释器、Job 身份和清理失败即停止。通过后才运行一次数据 worker，并对已有采样监督设置资源与时间上限；对相关数值库请求单线程，仅在受控子进程启动窗口生效，不能视为 CPU 硬配额。身份、缓存、预算、前向或清理失败均不重试、不重新抽样，部分进度只能按收据实际记录或标记未知。原始缓存、模型、逐条特征、得分及进度日志不上传。
