# 有限选种 BC V1：官方完整比赛验收

工程闭环 A 和预登记的有限模仿效果 B 均通过。训练学生明显优于同一初始权重，但仍落后冻结教师；没有超越教师或全游戏神经策略的结论。

## 网络究竟控制什么

网络为 289 → 128 → 64 → 5 的 ReLU MLP，只有 PLANT 任务内部的五类选种由模型决定。选种进入原来的种子检查、购种需求、资源预留、供给更新和实际动作生成；前面单位的预留会进入后面单位的特征。

原有种植机会判断、经济拒绝、施肥、浇水、及时收获、导航、任务分配、预算、雇工、销售和终局处理仍由冻结控制器负责。特别是顶层种植机会仍依赖教师评分；它是本轮范围限制，不是官方合法动作约束。未学习动物、扩地或完整联合经营策略。

正式学生 48 场中的 7,361 次选种全部由检查点决定，其中 634 次与该决策上下文的教师选择不同。发出的 2,524 次 PLANT 均由官方追踪确认成功，五类作物都实际种植过。购种规划调用 3,152 次，官方实际买到 2,560 粒种子，两者口径不同。模型错误不会回退教师；学生本面板经济拒绝为 0，初始模型为 5,196 次。

审计字段 `buy_seed_orders_changed_vs_teacher` 计数的是“购种序列不同的回合里，模型提交的全部 BUY_SEED 订单”，不是逐笔编辑距离或实际成交差额。正式学生该值为 210，仅用于证明存在购种决策影响，不能说成 210 粒新增种子或 210 笔不同成交。

输入采用同一个合法观测编码器，不使用对手 private、离线种子、未来轨迹、终局奖励、教师评分/排名或标签。原有隔离回归外，实际初始/训练检查点的 48 个对照也证明：改变不可见私有信息及种子，特征、logits、选择和完整动作不变。

## 训练、导出与正式入口

原计划优先 PyTorch，但官方 CUDA wheel 传输受阻。拟合前已登记改用独立 WSL 环境的 JAX 0.4.38 / Optax 0.2.4；依赖是既有可用 GPU 环境的物理副本，没有修改游戏环境、Lux 环境或驱动。游戏 Python 为 3.12.2，训练 Python 为 3.12.3。

最终复现的训练运行在 CUDA 上实际完成 2,880 次梯度与 Adam 更新，6 个权重张量发生变化。固定 80 epoch 中，验证损失选择第 9 epoch，对应 324 次更新后的检查点；后期验证损失上升，未以训练末轮替代所选模型。该次运行的数据准备/传输 0.83 秒、同步训练 45.22 秒（首次编译更新 1.52 秒）、验证 15.33 秒。这些耗时不包含前一次导出校验失败的拟合和冒烟训练，没有做 CPU/GPU 加速比实验。

训练和对局分开：部署是 NumPy CPU 推理，官方环境仍是 CPU。144 场四 Worker 端到端耗时 223.06 秒；这包含策略、框架、模拟和保存，不能当作 GPU 环境吞吐。

训练 GPU 默认矩阵精度曾使初始模型两个近似平局样本的 argmax 不同。导出校验改为同权重的完整 FP32 对照，训练设置未变；重复产生的所有权重与归一化参数逐项一致，失败检查点保留。正式初始/训练模型在全部 11,483 个样本上均与完整 FP32 argmax 相同；最大 logits 误差分别为 `1.43e-7`、`6.49e-6`。新进程的 float64 参考误差不超过 `1.43e-14`。

初始检查点 SHA256：`e476dc7a8f5ec8c09f94a9ebf07e0b22d4d1216acc4ad0119ae07b6a7611f431`。

训练检查点 SHA256：`9806383a2d335fdfe21639f911946b29b36708aba89f7b3961a4f9999b0388fd`。权重留在本地；同一批样本换回初始权重，会改变 9,124 个选种结果。

实际官方文件加载器不提供 `__file__`，入口已使用其编译文件名定位项目，并以显式最后 callable 别名注册 Agent。训练前后两个阶段共 4 场双方席位文件入口复现，与对应 Worker 的完整轨迹和检查点一致。缺文件、身份错、schema 错、非有限权重/输出均失败；没有教师回退。

## 验收、历史与证据边界

累计完成并官方复演 218 场：示范 60、正式 144、教师等价/学生冒烟/文件入口等 14；共 156,742 次官方转移。全部完整场次为 720 状态、719 次转移，双方 DONE、现金等于奖励，无错误/超时；公开与私有状态及背包顺序逐步一致。原始决策遥测、重载动作、种植效果和购种执行均复核，正式学生回退/加载异常/推理异常为零。

冻结的策略、模型、编码器、运行器和计算文件未改。测试启动后只新增实际模型隐私验收模块及统计 CLI 包装器。冻结统计器已经写出两份结果后，最后打印因缺少 `json` 导入报错；包装器只提供这个标准库名称，复算前后结果文件逐字节相同，没有改变任何统计方法或门槛。该细节见 `analysis-cli-repair.json`。

默认 Bot、教师、旧候选和历史实验保留；本轮失败安装、入口失败和导出失败证据也保留。市场择时 V1 的 192 场预留比赛没有运行。本轮不继续调参、不开展 DAgger、PPO、自博弈或新的教师研究。

公开代码与脱敏账本可复算统计；完整私有状态复演需在本地原始 Replay 或自行重跑上执行。公开哈希不是第三方已重算原始私有轨迹的证明。原始 Replay、逐帧遥测、训练数据、权重和设备清单不上传。
