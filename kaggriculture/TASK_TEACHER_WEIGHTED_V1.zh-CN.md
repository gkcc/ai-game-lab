# 固定任务类别权重的有限 BC：事前登记

本实验只改变任务选择 BC 的损失权重，重用已封存的 2,253 组旧训练样本；没有新增示范。冻结原训练器及模型，在独立副本中保持数据、schema、初始化与训练种子、组顺序、候选打包、优化器和 128 次更新的代码；真实组按教师所选任务类别赋权，padding 权重仍为零。同种子及相同代码不能证明历史两次执行的数值或 batch 完全相同。

按旧训练样本的已公开类别频数，固定 `w_k = min(2, sqrt(N / (5*n_k)))`。例如浇水约 0.4981、开垦为 2；缺类别或实际计数、缓存 SHA、训练 seed 与登记不符时停止。权重由训练样本确定，不使用已消费留出对局结果；动态候选宽度和 padding 筛选会改变实际 batch 暴露，不能用总体类别比例推算实际曝光。开垦仅 8 组，加权不能创造新状态，存在过拟合风险。

拟只进行一次受控 WSL JAX GPU fit，验收 128 次同步更新、非零梯度、参数变化及 16 组 CPU／GPU 推理对照；模型仅封存在本地，不自动晋级。已另预留 6 个种子，正式比赛需另行冻结对手、席位、统计口径和预算；种子排除基于既有元数据快照，不保证覆盖不可见或外部历史。本阶段不跑比赛、不做 PPO，也不读取失败面板。

启动前连续三次、间隔十秒检查主机可用内存至少 4 GiB；执行时 Windows 侧采样 2 GiB 可用内存停止门槛并通过取消标记通知 Linux guard，Linux guard 负责受控 session 的终止和清理。两侧清理分别留证；Windows 监督不等同于控制 WSL 或 GPU 显存，采样不是硬实时或 GPU 内存硬上限。随机 token 与 session 绑定用于防误调用，不是抵御同权限进程的安全边界。任何身份、资源、fit 或清理失败均停止且不重试。

旧模型和作物模型只在本地读取字节核对身份；训练产出的模型权重、原始训练缓存和进程日志不上传。事前本地提交只证明本地版本关系，不是可信第三方时间戳。真实训练是否完成、RTX 是否参与以及竞技表现均须等待执行证据，不得预先声称。

## 结果：技术训练通过，竞技效果待评估

事前本地登记为 `7f5f63b`。worker 报告一次已封存旧缓存快照，实际类别计数和权重与登记一致；GPU 完成 128 次同步更新，128 次梯度均非零，参数相对初始化发生变化。16 组、1,128 个候选的 CPU／GPU 推理对照通过，最大绝对误差约 `1.90e-6`；请求的是最高矩阵精度，没有测量硬件实际精度。

主机内存采样 194 次未触发停止；Windows transport 收据和 Linux session 收据分别报告清理完成。三次预检的具体数值没有逐次记录，内存与显存均不因此获得硬上限。冻结代码及 worker 收据支持设备验证与同步更新；独立子代理核对进度和 checkpoint 字节哈希，没有重新计算梯度、对照或运行模型。旧参考模型与作物模型的字节哈希复核未变。

新 checkpoint 仅保存在本地，未跑新比赛、未自动晋级；复用训练样本、类别加权和技术 fit 均不能证明泛化或收益提高。后续比较须在读取新留出结果前另行冻结完整面板与统计口径。
