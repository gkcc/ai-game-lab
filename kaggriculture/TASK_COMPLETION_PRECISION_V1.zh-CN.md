# 固定任务输入的 GPU 矩阵乘法精度对照

上一阶段在固定 16 组、1741 个候选上观察到 GPU/CPU 分数超出预设容差，但首选索引一致。本实验只改变同一 GPU 推理中的 JAX 矩阵乘法精度设置，检验这一设置是否影响该样本的数值差异；不训练、不读取留出集、不运行比赛。

绑定相同的未封存检查点、已消费训练缓存和本地设备身份，按缓存顺序取相同 16 组，每组只计算一次 CPU 参考；GPU 分别在进程默认设置和显式 `highest` 设置下对全部候选各运行一次，合计最多 16 次 CPU 和 32 次 GPU 组级前向。CPU 参考使用模型现有的 float64 路径，GPU 使用相同参数与归一化后的 float32 输入。

两组设置都按 `atol=1e-4`、`rtol=1e-5` 及首个最大值位置比较。报告每组设置的超差候选数、最大绝对误差和首选差异，并记录当前默认配置与上次汇总是否重现。若默认配置本已是 `highest`，两臂的请求设置相同；配置名称本身也不能证明硬件实际采用了何种计算精度。

仅一次尝试；身份、设备、有限值、行数、时间或清理检查失败即停止。过程记录已开始和已同步的组数及当前设置，不记录逐条结果。模型、缓存、个人设备配置和日志仅留本地；公开聚合数据及哈希。

即使某个设置减少了误差，也只能说明该样本在这次受控操作下的变化，不能唯一确定前次训练 `ValueError` 的原因，也不能证明模型的实战表现。预登记为本地记录，不是第三方时间戳。
