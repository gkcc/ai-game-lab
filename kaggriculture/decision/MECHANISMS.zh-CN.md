# 官方机制覆盖审计

本轮以本地实际安装的 kaggle-environments **1.33.0** 为准。引擎版本字段为 **0.1.0**；固定官方提交 `f994f2050d58d84f649329c1e35ce09ada7007c5`，规则文件 SHA256 `bc8a54879ef02c7ea64b8b333d6a976f0ea65c4949149d01f463f23bccee653e`。安装文件与该提交的 Git blob 逐字节相同，没有改 Server。

以下行号均指该提交的 [kaggriculture.py](https://github.com/Kaggle/kaggle-environments/blob/f994f2050d58d84f649329c1e35ce09ada7007c5/kaggle_environments/envs/kaggriculture/kaggriculture.py)。动作/观测外壳见同提交的 kaggriculture.json，框架观测拼接见 core.py:754–770；对象默认化、种子清理见 utils.py:150–195、199–231。中文旧文档和 Bot 估价公式不是规则权威。

## 口径

- **已完整建模**：仅在指定子问题及固定规则版本上，信息/参数/约束齐全并有执行验证；不表示会经营或知道最优价值。
- **已部分建模**：有可用分支/特征，但时间、联合约束或经济作用未全覆盖。
- **尚未建模**：控制器没有相应可选决策，不能称为优化后主动放弃。
- **已建模但策略不采用**：必须能够选择且有明确禁用/选择依据；本轮不把冻结 Bot 缺失的分支归到这一类。
- **尚无足够证据判断价值**：经济证据标签，可与上述实现状态并存。单步可执行不等于经营有利。

冻结对象是默认/第一版、第一轮与第二轮自动候选，以及现有第二版、按需购种版、市场版；四参数候选只改评分权重，不扩动作。对上述策略源码检查未发现 BUY_LAND、BUY_ANIMAL、BUY_PRODUCT、BUILD_COOP/PASTURE、PICKUP、PLACE、FEED、CARE、COLLECT_FERTILIZER、FERTILIZE 分支。

下面按12个机制族维护。**冻结策略为9族部分建模、3族未建模；没有一族可称为全经济过程已完整建模。** 粒度是人为定义，不能把这个计数当竞技分数。动作层面能发出10/18个单位操作类别、3/6个市场类别；新接口能表达全部18+6类，但这也不是学习能力证明。

## 执行顺序与三个不同概念

[rules-catalog.json](rules-catalog.json)逐项导出固定引擎的作物/动物首产、间隔、上限、成本，全部9商品价格参数、8店需求、购地价格与顺序；不是手抄另一套仿真器。未来策略可将这些常量作为先验，实际配置覆盖仍优先。特别是动物生产的细节：只要尚未因连续两夜缺食逃走，生产日即便未喂也会有基础1产出；只有喂食的生产日兑现已有照料奖励，生产分支随后清空奖励余额，最后才累计当天同时喂食且照料的+1。这使“隔日喂食”和“每日照料”的长期比较值得验证，本轮没有据此实现新经营规则或声称盈利。

```text
主农夫、工人（先全队种子请求检查，再顺序执行）
  → 市场订单位置0、1、…（双方逐单位同步报价）
  → 城镇消耗 → 作物衰败 → 到日界则刷新/卸货/解雇/抽店 → 现金终局
```

1. **框架协议**相当宽松：根动作不是对象时，utils.default_schema会替换为默认对象；未知操作通常是游戏静默no-op，不等于INVALID。参数不可int转换时某些单位操作还可能抛异常。不能只看比赛没报错判断动作做成了。
2. **状态相关不可执行**：如格子未买、未携带肥料。`assess_unit`只回答旧状态下的孤立动作；先DIG后PLANT时，第二个动作的孤立结果不能作联合mask。
3. **经济偏好**：施肥增产已封顶、季末买地、低价出售仍可合法执行。模型必须能主动放弃或选择，而不是被旧启发式永久封锁。

市场“缺钱/缺货/仓满”不是一般的联合硬mask，之前的DROP/SELL或其他订单可改变它。`assess_order`只标注与当前队列无关的确定不可能（不支持的商品、地已买完），其他条件明确返回conditional。这里**尚未实现完整联合动作的精确可行性求解器**；未来自回归策略要沿官方顺序维护已确定资源，并对不确定的对手报价保持保守/条件标签，不能偷偷用近似价删除动作。

## 实证边界

29个自动用例在固定官方引擎执行，既有正例也有no-op、冲突、资源顺序与完整运行观测验证。它们证明表达与执行，不证明动物、施肥或扩地最优。

本轮不把缺失机制判断为无价值。买地只有一种受控干预；动物、肥料、超过7工人、择时扩地、选择性运输仍缺完整经济对照。维持本表时新增机制必须同时附官方依据、实现状态和证据标签；不能以一个原语名“已支持”代替联合经营与长期价值建模。
