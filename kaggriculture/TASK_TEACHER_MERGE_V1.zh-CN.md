# 教师任务示范合并接口

新接口将旧示范与未来经过验收的新示范按原顺序合并，并将变长候选数组转换为现有任务选择训练器的组输入。它检查数组类型、维度、有限值、候选偏移和标签，要求旧／新训练种子互不重叠并与留出种子隔离；`to_groups` 也单独检查训练和留出角色。原数组不会被修改。

接口在训练前拒绝单组超过 65,536 个候选，和现有训练器的显式上限一致。4 项纯合成测试覆盖变长候选和标签对齐、输入不变、非法种子／数据／预算、65,536 和 65,537 边界，并实际调用既有训练器的 `as_groups`、`validate` 和 `inputs` 检查 373 维输入。测试没有调用 `fit` 或 GPU。

**接入责任：**`merge` 接收已加载的数组，不验证来源归档的 SHA 或特征名称。未来调用方必须先认证两份不可变归档及共同特征 schema，再传入已登记的训练和留出种子；不得将部分完成的失败对局当作新数据。数组合并和组转换会产生额外副本，组数／候选预算不是进程内存硬上限。

本轮未读取真实训练数组、模型或轨迹，未运行比赛或训练，因而不能证明模型改进或真实 fit 可行。代码与测试完成后才记录身份和独立审查，不冒充事前实验登记。旧模型、默认 Bot、规则和历史证据不变。
