# 固定 16 组 GPU/CPU 对照：启动修复版

上一版本在写入尝试标记后因变量解包错误退出，没有启动 GPU。旧源码、标记、失败审查、哈希和逾时记录保持原样；本版本是另行登记的一次新尝试，不退款或重试旧尝试。

本版只修正启动初始化与失败留证。尝试标记一经创建，后续配置读取、启动、监控和清理均纳入异常记录；标记部分写入时记录不完整状态，进程构造已进入但没有返回句柄时，生命周期和清理状态标为未知。合成测试覆盖正常入口、部分标记、配置、进程创建、运行、清理、状态查询和收据写入异常，以及重复尝试拒绝。

数值比较复用上一版本的代码：同一私有检查点和已消费训练缓存，固定取前 16 个可观察完成组，最多 8192 个候选；GPU/CPU 比较全部 logits，`atol=1e-4`、`rtol=1e-5`，逐组首个最大值须一致。一次无梯度 GPU 诊断，不训练、不读取测试面板、不新增比赛或官方步骤。任何身份、设备、资源或进程清理失败均停止，不重试。

对照仅描述当前固定输入下的推理一致性，不证明之前训练异常的唯一原因或模型竞技能力。公开只含源码、聚合数值、清理与哈希；权重、缓存、逐条 logits、设备配置和日志均留本地。预登记是本地记录，不是第三方事前时间戳。

## 实际结果

预登记提交 `ea2c093` 后，一次修复版诊断完成。实际执行了 16 组 GPU 前向、共 1741 个候选；数据均有限，设备身份与本地冻结配置一致，Windows 与 WSL 两侧自有进程清理收据通过。没有梯度、训练更新、测试集读取、新比赛或官方步骤。

按照事先固定的 CPU 参考容差，**1402 个候选分数超差**，最大绝对差为 `0.001991641066183547`；16 组的首个最大值索引全部一致。因此执行链通过，但数值一致性门槛未通过。独立子代理核对了源码、公式、哈希和运行收据，没有独立重算这些 logits；16 组也不是随机代表性样本。

该差异符合旧训练对照函数可能抛出 `ValueError` 的条件，但不能据此唯一确定当时的异常位置或原因。旧训练仍未验收，模型未封存、部署或晋级。独立建议另立无梯度控制实验，对同一输入比较 GPU 默认矩阵乘法精度与 `highest` 设置；若误差变化，可为该样本的差异提供依据，仍不能直接推导竞赛收益。
