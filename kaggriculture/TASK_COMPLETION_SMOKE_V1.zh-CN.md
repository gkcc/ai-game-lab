# 已封存任务模型：官方对局接入冒烟

本实验只检验上轮封存的任务选择模型能否在官方对局中被真实加载、调用并影响动作。保留同一作物模型、控制器、官方引擎和市场版对手；对照臂使用冻结任务教师。一个新种子、交换双方席位，每席位分别运行模型与教师，共 4 场。

训练样本、权重与策略不改变，不进行任何新训练。固定四场主复演及预先指定的候选方零号席位独立复演，共最多 6,471 次官方状态转移；独立复演在所有 callback 身份中按哈希选 20 条，选择不依赖预测结果或动作类别。额外动作分析只读取这四场回放和四份 trace 各一次，不额外运行官方状态转移。

必须核对模型及作物检查点身份、非零任务模型调用、无回退与无 Agent 错误、完整 720 状态／719 次动作、官方复演及自有进程清理。对照比较只在状态共同前缀且完整选择器输入相同的地方进行；只有模型选择差异与完整请求首次差异发生在同一回合，才记为观察到模型关联的请求影响。模型选择、提交请求、官方事件状态和长期完成分别计数，不用终局现金差声称某个动作造成了收益。

四场、一个种子只能作为接入与动作影响的有限证据，不能证明胜率、统计显著性或泛化，也不自动晋级。如果没有观察到请求影响或没有施肥机会，明确报告证据不足，不针对这个种子更改模型或门槛。时间上限在文件读取、记录和引擎事件之间检查，单次解压或 JSON 解析不可抢占。

公开登记是本地提交，不是第三方时间戳。原始回放、逐条 trace／观测、模型权重、机器配置和日志只留本地。保留旧阶段及默认 Bot，不进行 PPO、DAgger 或大规模训练。

## 实际结果

事前提交 `96eda51735c40ca0f685bd4e88d6705fc829c23d`。提交前扫描拦截了测试中一个通用的合成 Windows 路径字面量；将其拆分拼接后测试输入不变，原未执行冻结、审查和源码哈希已归档。独立复审重新核验了修订，17 项合成测试通过；实际提交后恢复完整 Git 与冻结检查。

四场均为 720 状态、719 次动作、双方 DONE、零 Agent 错误，四场主复演通过。两个候选局各有 2,212 次任务模型前向、118,411 个候选行，教师局任务前向为零；两臂都继续使用相同冻结作物模型。比赛中任务模型使用 CPU 推理，本轮没有重新训练或使用 GPU。

双方席位的模型／教师对照中，首次完整请求差异均在第 2 步（从 0 开始），并与同一回合、相同选择器输入下的模型选择差异相连。后续物理状态分叉后不再将跨臂选择归因到相同局面。这个观察证明该测试中模型选择影响了提交给官方规则的请求；它不单独证明长期任务完成或收益因果。

每场模型局均有 251 次包含 FERTILIZE 候选的 callback、72 次选中 FERTILIZE、24 次提交 FERTILIZE 工作请求；主复演的官方事件流记录这 24 次均发生原子状态变化。它们分别是调用、选择、请求和事件计数，不能当成 251 个独立任务或经济收益证据。

两个席位得到的数值相同，上表适用于每个席位；它们属于同一个种子，不能当作两个独立随机样本。模型自身净收益比教师低 707，现金差高 519；这只是该种子的描述，不能据此判断竞技改进或推断某个动作的财务影响。

独立复演固定候选方零号席位，719 步，按身份哈希预选的 20 条 callback 全部匹配：WATER 16、HARVEST 2、PLANT 1、FERTILIZE 1、DIG 0。它共用官方引擎及 `validate_trace`，未独立重算模型分数，也不是独立规则引擎。另一次分析只读取四场回放及四份 trace 各一次；总官方转移 6,471。独立子代理复核了聚合账本与源码，但没有重读原始文件或逐帧复算。

该阶段的模型接入和请求影响冒烟通过；收益与泛化仍需新的、预先登记的多种子评估。旧未封存模型、旧失败、默认 Bot 和官方规则保持原样；原始回放、trace、权重和个人配置均留本地。
