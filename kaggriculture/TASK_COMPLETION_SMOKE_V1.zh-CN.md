# 已封存任务模型：官方对局接入冒烟

本实验只检验上轮封存的任务选择模型能否在官方对局中被真实加载、调用并影响动作。保留同一作物模型、控制器、官方引擎和市场版对手；对照臂使用冻结任务教师。一个新种子、交换双方席位，每席位分别运行模型与教师，共 4 场。

训练样本、权重与策略不改变，不进行任何新训练。固定四场主复演及预先指定的候选方零号席位独立复演，共最多 6,471 次官方状态转移；独立复演在所有 callback 身份中按哈希选 20 条，选择不依赖预测结果或动作类别。额外动作分析只读取这四场回放和四份 trace 各一次，不额外运行官方状态转移。

必须核对模型及作物检查点身份、非零任务模型调用、无回退与无 Agent 错误、完整 720 状态／719 次动作、官方复演及自有进程清理。对照比较只在状态共同前缀且完整选择器输入相同的地方进行；只有模型选择差异与完整请求首次差异发生在同一回合，才记为观察到模型关联的请求影响。模型选择、提交请求、官方事件状态和长期完成分别计数，不用终局现金差声称某个动作造成了收益。

四场、一个种子只能作为接入与动作影响的有限证据，不能证明胜率、统计显著性或泛化，也不自动晋级。如果没有观察到请求影响或没有施肥机会，明确报告证据不足，不针对这个种子更改模型或门槛。时间上限在文件读取、记录和引擎事件之间检查，单次解压或 JSON 解析不可抢占。

公开登记是本地提交，不是第三方时间戳。原始回放、逐条 trace／观测、模型权重、机器配置和日志只留本地。保留旧阶段及默认 Bot，不进行 PPO、DAgger 或大规模训练。
