# 未封存任务模型的 GPU/CPU 数值对照

前一阶段的一次训练进程失败并留下了可加载、但未封存的私有模型。此诊断只检查该模型在已消费训练缓存上的推理一致性，不重训，不读取测试面板，也不运行游戏。

在读取数值数组前绑定既有检查点、缓存、特征 schema、源码及私有 GPU 配置的 SHA。按缓存顺序固定取前 16 段 `completed_observed`，不根据结果替换；总候选上限 8192。GPU 和 CPU 使用同一权重与归一化，比较全部候选 logits，条件为 `atol=1e-4`、`rtol=1e-5`，每组第一个最大值的位置还须相同。普通数值不一致仍完成全部 16 组并如实报告；身份不符、非有限值、设备不符或超时则停止。

最多 16 次组级 GPU 前向，不计算梯度，不新增比赛、官方步骤或留出读取；失败不重试。子进程记录阶段及已同步组数，并分别核验 Windows 和 WSL 自有进程清理。结果只能描述这些固定输入下的数值差异，即使重现差异，也不能单凭它证明前次 `ValueError` 的唯一原因，更不能证明实战实力或模型可部署。

只公开聚合误差、候选数量、进程清理和身份哈希；模型、缓存、逐条输出、设备配置及日志留在本地。预登记提交是本地记录，不是第三方时间戳。
