## 游戏概况

双方各自管理农场，通过买种子和动物、播种、浇水、收获、养殖、雇工及动态市场交易，在固定季度中赚取尽可能多的金币。

- 农场默认 10×10，四个 5×5 象限。初始开放左上 `NW`，可用 `BUY_LAND` 依次购买右上、左下、右下，费用 1000、2000、4000。
- 启动资金默认 3000。
- 一名主农夫，可每天雇用工人。每个单位每回合独立执行动作。费用为 `farmHandCostMult * fib(n)`，默认倍率 1，序列 `1,1,2,3,5,8,13,21,…`，每天重新开始。
- 作物为小麦、胡萝卜、番茄、草莓、西瓜，各自有种子价、生长期、产量和基准售价。
- 一次性作物从 `ceil(max_yield_day/2)` 开始，窗口内每天浇水加 1 份产量；施肥让加成在 3 天内翻倍。多次产出的作物每次基础 1 份，当天浇水且施肥时为 2 份。
- 鹅产蛋，需要鹅舍；牛产奶、羊产毛，需要牧场。每天喂小麦；喂食且照料会积攒下次生产加成；每天还可收一份肥料。动物能持续生产，`max_held` 限制地块积存量，不限制一生产量。
- 连续两个日终缺水／缺食，作物变杂草、动物逃走。播种当天就计入未浇水次数。
- 作物超过最大寿命会每隔一回合损失一份待收产量，降到零成为杂草。
- 空的已解锁地块日终有 `0.005` 概率生杂草，用 `DIG` 清理。
- 仓库非种子物品容量 100。种子独立存放，播种直接扣除，不需要 `PICKUP`。
- 市场种子和动物固定价；产品售价随库存动态变化，最低 1。高价作物、牛奶、羊毛尤其容易因过剩跌价。`BUY_PRODUCT` 仅支持小麦和肥料；所有产品均可卖。每人每回合默认最多 10 条市场订单，超出忽略。
- 城镇中心默认每天消耗各类非肥料产品 1 份；每 3 天随机、有放回解锁一家商店，最多 8 家。每家每 4 回合消耗需求品各 1 份，单品类商店翻倍，重复商店独立消耗。
- 一季名义 24×30=720 回合。季末现金决定胜负，可平局；本地默认实际记录 720 个状态，包括初始状态。

## 编写策略函数

策略函数接收观察数据，返回动作字典。本地项目使用 `agent(observation, configuration)`，也支持官方示例中的单观察参数形式。

### 输入 observation

| 字段 | 中文含义 |
|---|---|
| player | 我方玩家编号，0 或 1 |
| step | 全局回合编号，从零开始，由框架提供 |
| day | 游戏天数，从零开始 |
| hour | 当天回合，默认从 0 到 23 |
| farms | 双方公开农场列表，按玩家编号访问 |
| private | 仅我方可见的仓库、种子与个人背包 |
| market | 共享市场库存、售价 |
| town | 共享的已解锁商店列表，允许重复 |

每个农场包含：`money` 资金、`tiles[y][x]` 地块、`farmer=[x,y]` 主农夫位置、`hands` 当日工人位置、`unlocked_quadrants` 已购象限、`hires_today` 今日雇用次数。

地块为 `None` 空地、`"LOCKED"` 未买土地、作物字典、杂草字典或动物设施字典。作物包含品种、播种日、今日浇水、连续缺水、可收产量、寿命和肥效；动物设施包含动物类型、放置日、产量、喂食、缺食、照料、肥料和待发照料加成。每个字段的完整表见[接口与通信说明](接口与通信说明.md)。

私人数据含：`shed={物品:数量}`、`seeds={作物:种子数量}`、`inventories=[主农夫背包,工人1背包,…]`。

市场含 `inventory={产品:库存}`、`prices={产品:当前整数售价}`。城镇含 `unlocked_shops`，同名店每个实例都独立消耗。

### 输出动作格式

```python
{
    "farmer": [op, ...args],        # 主农夫的一条指令
    "hands": [[op, ...args], ...],  # 按输入工人顺序各给一条指令
    "market": [[op, ...args], ...], # 按列表顺序处理的市场订单
}
```

上面是结构示意，`op` 和 `args` 是占位符。实际可返回：

```python
{"farmer": ["WATER"], "hands": [["NORTH"]], "market": [["SELL", "MELON", 6]]}
```

### 农夫和工人指令

- 移动：`NORTH`、`SOUTH`、`EAST`、`WEST`；等待：`PASS`。可以经过未买土地，但不能在未买土地上耕作。
- 仓库：`PICKUP <item> [n]` 取出；`DROP` 全部卸货；`PLACE <item> [n]` 在仓库旁放指定物品，也可在匹配设施上放动物。仓库接入格是零基坐标 `(4,4)`、`(5,4)`、`(4,5)`、`(5,5)`，仓库本身不是地块。
- 作物：`PLANT <crop>` 播种、`WATER` 浇水、`HARVEST` 收获、`FERTILIZE` 施肥。
- 动物：`BUILD_COOP` 建鹅舍、`BUILD_PASTURE` 建牧场、`FEED` 喂食、`COLLECT_FERTILIZER` 收肥、`CARE` 照料，产品也用 `HARVEST` 收获。
- 地形：`DIG` 移除作物、杂草或空设施，有动物的设施不能拆。

### 市场指令

`["BUY_SEED",crop,n]`、`["BUY_PRODUCT",item,n]`、`["BUY_ANIMAL",animal,n]`、`["SELL",item,n]`、`["HIRE"]`、`["BUY_LAND"]`。不合法的动作可能无提示地变成空操作。

### 示例：小麦循环

小麦首次产出年龄为 2 天，最大产量年龄为 4 天，加成窗口为第 2～4 天。以下保留官方示例逻辑：买种、播种、浇水，年龄至少 2 天时尽快收获，并出售仓库小麦。它只演示接口，不是完善的赚钱策略。

```python
def agent(obs):
    player = obs["player"]
    me = obs["farms"][player]
    private = obs["private"]
    fx, fy = me["farmer"]
    tile = me["tiles"][fy][fx]

    market = []
    if private["seeds"].get("WHEAT", 0) == 0 and me["money"] >= 10:
        market.append(["BUY_SEED", "WHEAT", 1])
    # 卖掉仓库里已有的小麦。
    wheat_in_shed = private["shed"].get("WHEAT", 0)
    if wheat_in_shed > 0:
        market.append(["SELL", "WHEAT", wheat_in_shed])

    if tile is None and private["seeds"].get("WHEAT", 0) > 0:
        return {"farmer": ["PLANT", "WHEAT"], "hands": [], "market": market}
    if isinstance(tile, dict) and tile.get("kind") == "PLANT":
        crop_age = obs["day"] - tile["planted_day"]
        if crop_age >= 2:  # 小麦最早两天后收获。
            return {"farmer": ["HARVEST"], "hands": [], "market": market}
        if not tile["watered_today"]:
            return {"farmer": ["WATER"], "hands": [], "market": market}

    return {"farmer": ["PASS"], "hands": [], "market": market}
```

## 本地测试

官方安装示例：

```bash
pip install -U kaggle-environments
```

本机已经固定依赖部署完成，直接用 `Play.ps1` 即可，不需要执行上面的升级。

Python 或笔记本中可以直接传入函数或 `.py` 路径：

```python
from kaggle_environments import make

env = make("kaggriculture", configuration={"episodeSteps": 720}, debug=True)
env.run([agent, "random"])  # 也可以传入 ["main.py", "random"]。

final = env.steps[-1]
for i, s in enumerate(final):
    print(f"玩家 {i}：奖励={s.reward}，状态={s.status}")

# 在笔记本中显示。
env.render(mode="ipython", width=1200, height=800)

# 保存完整回放，供可视化或离线分析。
import json
with open("replay.json", "w") as f:
    json.dump(env.toJSON(), f)
```

内置策略名：`pass` 始终等待、`random` 随机、`starter` 确定性入门策略。本地完整比赛入口：

```powershell
& ./kaggriculture\Play.ps1 -Seed 42
```

## 提交策略

提交包根目录必须有 `main.py`，其中定义 `agent` 函数。

单文件：

```bash
kaggle competitions submit kaggriculture -f main.py -m "小麦循环第一版"
```

多文件：将 `main.py` 放在压缩包根目录。

```bash
tar -czf submission.tar.gz main.py helper.py model_weights.pkl
kaggle competitions submit kaggriculture -f submission.tar.gz -m "多文件策略第一版"
```

从笔记本提交；替换下面的用户名、笔记本名和版本：

```bash
kaggle competitions submit kaggriculture -k YOUR_USERNAME/kaggriculture-agent -f submission.tar.gz -v 1 -m "笔记本策略第一版"
```
