# DAgger 学生条件示范采集：运行前复核

来源适配器以固定 Git 提交的已完成结果根证书和两层独立审查为入口，只枚举 24 条已完成游戏记录；逐场读取时验证原 job、row、官方 audit、complete、Replay、trace 与 wrapper 身份。模型通过已有公开承诺和本机 baseline 绑定的摘要链核对，未调用会解析旧未运行 seed 清单的历史库存工具。真实只读元数据预检已通过，加载了冻结网络的归一化和 schema，但未读取旧比赛、trace 或未运行清单，也未运行模型前向。

独立预审发现两个来源生命周期反例：仅物理读完文件可能被误认作语义扫描完成，以及扫描后上下文异常仍可能允许第二遍。均已修复为由来源对象执行完整 719 行语义扫描，只有扫描成功且上下文正常退出才允许第二遍；另以合法摘要但末行语义损坏、第三次访问等合成反例复核。来源对象只在单个 context 内计次，跨进程的独占 attempt 与失败封存由总入口负责。

另一名子代理独立核查每窗四个不同 step 的坐标哈希排名、全池原始／标准化 float32 传递闭包、标签冲突排除、训练优先去重及二遍 roster／上一预算核对；选择过程不读取反事实结果。旧扫描器的 `selection_work` 仍是旧三窗口计数，不作为本阶段六窗口的采样工作量。总入口一项纯合成故障检查发现 attempt 曾晚于来源认证创建，已修复；再次检查来源失败、现存 attempt、计划篡改、二遍候选变化及单步异常均不生成成功结果。还发现最后封存失败时结果文件可能被误当成功，入口改为 provisional 与摘要绑定的 closed；模型路径异常的 CLI 输出也改为脱敏类别。

新来源、采样、计划、数据整理、既有比较与官方单步及集合目标的相关合成回归共 99 项通过，包括完成封存和非法命令行参数不回显隐私的回归。完整的 24 场来源适配、真实计划、样本门与资源消耗仍须在事前冻结后执行并独立复核；这些测试没有训练模型或运行完整比赛。历史只读盘点曾解析含未运行 seed 的旧清单，范围见[说明](../task-source-inventory-v1-20261031/NOTE.zh-CN.md)，不将其声称为从未读取。
