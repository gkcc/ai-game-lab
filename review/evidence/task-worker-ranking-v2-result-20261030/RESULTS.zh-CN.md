# 冻结任务头工人排序：V2 离线比较结果

事前登记 `ae9f072` 后，真实 Git 登记／工作区字节预检通过；V2 唯一正式入口退出码为 0，运行器报告覆盖门槛达标、两头已加载并完成评分。已固定的两份档案合计 5,104 个决策组、322,151 行候选；只分析教师选 `PLANT` 且同一目标至少有两个不同工人候选的组，合格组达到总数至少 20、四个来源簇且每簇至少 5 的事前门槛。五组不是五场独立比赛，精确合格数量不公开。

按每簇内部求均值、四簇等权，**早期原教师示范 BC 任务头 A 在同目标教师单位 top-1 上，比合并示范 BC 任务头 B 高超过 5、至多 20 个百分点**。在上述筛选出的 `PLANT` 组内，全候选联合护栏通过，含义是全候选教师 top-1 与全候选同目标 `PLANT` 两项的 A−B 均不低于 −5 个百分点；它不意味着两项均提高，也不评价教师选择其他任务的组。公开的统计指标只包含事前固定的粗档和联合护栏，不公开单模型准确率、单簇计数、精确差额或交叉表。

一名独立子代理从两份封存档案重新读取，独立实现筛选、排名、按簇统计和分档，CPU 重新评分后得到相同门槛、粗档与护栏；其进程退出码为 0，报告复算本身的额外评分次数和候选行数各未超过原单次预算，未把原执行与复算合计当作单次额度。该复算复用了认证档案读取器和冻结 `TaskNetwork` 评分实现，不是独立模型实现。另一名子代理只读核对保存结果、源码身份、旧失败证书与默认 Bot，未读取档案或模型，也未重复推理。

这不是独立留出：两份档案来自四个已消费开发簇且保留分布有意偏采样。A 未使用这些登记簇训练，但部分状态由 A 参与产生；B 曾使用两份档案训练，原历史批次索引缺失，不能断言本次每组都参与过权重更新。两个模型的训练来源和历史不同，结果不证明导致差异的原因，也不能外推显著性、完整官方动作、成功种植或比赛收益。早期头之前的官方能力保留评估未通过准入，不能因本次离线排序更高而替换默认 Bot。

本阶段的评分与独立复算均使用 NumPy CPU；没有新增训练、比赛或官方状态转移。执行范围与 GPU 状态来自程序及复核报告，没有系统级文件访问或 GPU 活动监控。模型哈希与加载是两次读取，前后核对不是操作系统锁；公开粗档与护栏也不是形式化匿名保证。V1 原失败、已有模型、官方规则和默认 Bot 保持原样。
