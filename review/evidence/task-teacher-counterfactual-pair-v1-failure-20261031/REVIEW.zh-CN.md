# 独立复核与证据范围

一名独立子代理核对五阶段的 claim、子进程、Job 与 accepted 摘要链及累计写入账目；五份 Job 均记录零退出、进程回收和成员清零。第六单元无 claim、Job、子进程或接受标记，失败收据记为无活动单元，未生成完整实验封存。另一名子代理只读检查了登记停止边界、证书措辞和脱敏范围。

复核没有重读逐组轨迹、计算收益或重跑官方游戏；两局完成、控制复演和历史对齐的证据来自 Worker／Job 与验收收据，不是这次独立逐帧重算。Job 内存数据是有限采样；停止瞬间的可用内存没有被记录，不能用事后读数归因。

状态比较排除剩余时间字段并规范普通字典顺序，背包及仓库顺序另验；trace 只规范作物推理耗时。官方复演的 Python 等值比较与原始字节比较不同。

公开记录不含候选坐标、实际 seed、模型或私有计划摘要、逐场收益和原始 Replay；不能保证形式匿名。此失败不改变历史实验结果、状态残差失败结论或默认 Bot。
