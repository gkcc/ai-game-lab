# 下一阶段：先验证短窗收获收益信号

本轮联合解码器在两组已消费开发组合上均减收，按登记停止该分支。上一轮八组单点教师替换也没有显示正收益；两者都不适合被直接包装成更优 BC 标签。

独立规划子代理建议：选四个已消费种子角色，每个最多一个预先固定的收获机会，比较原选择和一次 HARVEST 选择替换的 48 步真实现金结果。维护者采用这个收窄方向。它服务于“用官方经济结果检查监督标签”，不继续匹配调参，不将教师首选默认当作最优答案。

历史 [收益归因](../../../kaggriculture/PROFIT_ATTRIBUTION.zh-CN.md) 中，FH 相对 F 减少产量截断 28.53、实际产量增加 26.53、销售收入增加 5,384.83，说明及时收获值得研究。那是旧完整面板的账目解释，不能据此认定任意一次 HARVEST 替换都更优，也不能把增量移植到当前模型。

## 先验证恢复和可执行性

现有官方 [单步恢复入口](../../../kaggriculture/learning/task_student_continuation_v1/official_step.py) 复制完整双方状态、configuration 和 info，并用占位前缀保持官方步号。固定规则在日结按 info.seed 和日期构造局部随机数，因此该恢复不需要执行官方前缀转移。官方 core 的 clone 未传 info，不能直接代用。已有实证只证明单步，48 步正确恢复尚未验证。

两臂必须分别新建原 BoundedAgent 与冻结对手，从第 0 帧输入各自合法历史观测，重新计算并核对请求、稳定 trace 和累计预算。不得手工修改 previous 或清零预算从中途继续。没有官方前缀转移，并不意味着没有模型与控制器前缀成本。

事实分支先用重建 Agent 实际产生的请求连续运行 48 步，逐帧复现原 Replay，包括公开／私有状态、背包和仓库顺序；失败停止。之后才允许干预臂在同样重建的前缀上替换一次已冻结的 HARVEST 候选，后续恢复原学生，对手按当前分支观测重新决策。候选意图与实际请求／状态变化分别留证。

## 小预算与信号门

本阶段计划最多四个点、两臂各 48 次官方 step，合计 **384 次官方转移**；事实臂本身承担复核，不追加未计入预算的官方复演。环境完整帧构造另计；正式实施须记录实际调用，不将源码推断替代执行计数。

八臂的模型前缀和后缀分别计费，每臂沿用原完整 episode 预算。全阶段上限：学生控制器 5,752 次、对手调用 5,752 次、任务前向 32,000 次、作物前向 64,000 次、输入总行数 1,280,000。完整比赛、训练、GPU 计算、新种子均为零。时间、内存和输出空间还须在新登记中具体冻结。

只使用当时合法观测已经表达的 HARVEST 候选，优先同单位可实际收获且背包有空间的机会；具体角色、席位、时间范围、回调坐标和替换 ID 在查看反事实收益之前冻结，缺失点不补抽。

初拟继续扩大标签采集门：至少三个有效且请求／状态不同的配对；至少两个不同种子有非零 48 步现金差信号，其中包含事前指定的诊断角色；信号中有正也有负，至少一个现金差正例自身现金不下降；所有技术检查通过。具体定义和坐标随下一阶段代码一次性登记，不能根据收益重写。即使过门，也只表示值得进一步研究短窗标签，不启动本阶段训练。

逐商品保留窗口末背包、仓库和未收获产量，未售库存不按预测价格计入现金。48 步截断会遗漏后续投资回报；共享市场和对手响应也会影响结果。四个已消费点不能证明终局收益、独立泛化或学习型 Bot 变强。未来轨迹只用作标签，不进入部署决策输入。
