# 独立预审与真实来源复核

独立子代理没有参与本轮实现。它审阅 runner、worker、core、gate、selection、contract、登记，以及复用的来源认证、owner、trace／Replay 入口。

执行前独立实跑全部 48 项合成回归，零跳过；CLI 帮助退出正常；测试未导入官方引擎或 torch，自有临时目录实际删除。预审无执行阻塞；指出 HARVEST 还有动物分支，登记已在冻结扫描前把 PLANT 条件限定为本实验研究的作物收获。旧 NEXT 的背包容量措辞由新登记明确更正，旧文件没有改写。

准备入口退出 0、四点全部缺失后，独立子代理进行只读实证复核：

- 核对 selection-started、四个 selection、selection-closed、binding 的关联与源码冻结。
- 核对 421 项当前来源 SHA、401 项历史来源保留关系、默认 Bot 与冻结资产；经安全入口重新认证旧 32 场来源链及压缩文件身份，没有读取未运行的留出清单。
- 完整复读四份 trace 到 EOF，总计 2,876 行、8,879 个 callback；窗口内 5,723 个，与逐角色记录一致。
- 复算冻结选择器的完整返回值，并另写资格布尔判定计数；两种方法均为零合格 callback 和候选。
- 在复核进程亲见退出 0；内存守卫调用 16,402 次未触底。该数字是离散守卫调用，不是连续最低内存证明。

该独立复核没有加载权重、调用模型或官方转移，也没有修改文件。复核阶段官方引擎及 torch 均未导入。它没有额外存储原因分类，不能据此声称“原选择已经选中率 100%”。

审查结论为：**覆盖预筛结果可靠，没有必须先修的缺陷；本轮没有真实窗口收益证据。** 不能把预审和合成回归升级成连续 48 步实测，也不能把四个 missing 当作零收益。

维护者随后封存八份私有记录，并另核验上一轮 127 原件及盐承诺。发布前独立子代理又逐字节重哈本轮八份原件（94,672 字节）、重算新盐承诺，核对 coverage 投影、summary SHA 和 PROGRESS 冻结前缀，全部一致；没有重复读取四份旧 trace。上一轮 127 原件的本次核验由维护者完成，不能冒称本子代理也重算了所有旧档。公开材料仅披露计数、代码及盐化承诺，外部审查者不能仅凭摘要重建原始私有轨迹。

推荐下一步单独冻结只读覆盖分解，先分清候选缺失、其他单位机会、原选项已包含收获及同回合稍后派工；不补抽本轮点、不开始训练或完整比赛。
