# 运行前独立复核

独立子代理以合成数据核验状态与候选的非线性交互、零输出保持基线、掩码和梯度，并在 JAX CPU 上完成 64 次合成更新。针对可复现的公共分数偏移、残差计算顺序及不同 padding 宽度反例，训练先对 float64 基线去共同偏移；部署也分别去掉基线与残差的共同偏移，并对实际训练宽度及最大宽度建立数值和首选检查。两种检查与训练梯度程序分别编译，不能宣称训练内核逐位等同。

训练与诊断使用两套特征连通图。独立测试确认：诊断特征桥接和诊断目标变化均不改变训练组保留；诊断本身的冲突与覆盖仍可能使整次实验不启动。入口的来源／模型绑定、学生索引前后核对次序、数据门、参数封存、受控 Job 及失败不封存均用合成替身检查。针对汇总消费者构造的不可能角色窗口数、去重分量计数和改正／回退计数反例已补检查与回归。

本次复审未读取真实样本、重跑历史来源或执行真实训练与游戏；它不能证明实际数据通过数值门、诊断结果可信泛化或比赛收益改善。已有诊断汇总在本阶段前已观察，仍属于开发数据；结果和正式独立对局必须分别报告。
