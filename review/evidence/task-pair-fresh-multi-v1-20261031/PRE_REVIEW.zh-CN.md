# 新种子多对手探索：登记前复核

独立子代理确认旧种子工具只检查保留语境，不能独立覆盖训练与历史角色；新准备器改为保守扫描固定 Git JSON 和已识别本地元数据，并显式验证此前 192 场面板的 12 个保留种子。只读全量库存检查覆盖 1,679 个 Git JSON、4,180 个已识别本地元数据及四份受保护文档，12 个正式保留角色均被排除；未知或已删除资料仍不在范围内。审查中发现并修复了文本科学计数、长前导零、Unicode 转义、点分隔路径及大指数解析的合成反例；最终源码的只读库存重新扫描通过，未生成新种子。

调度器复用现有官方 Worker、Job、逐场验收与消费者，只筛选每批 16 个目标坐标；独立审查确认 auxiliary 不被调度、共享预算不因切批重置。另发现授权后失败可能留下可误用 permit：入口现验证存活父进程、PID 创建时间、共享截止和所有失败／关闭标记，异常或完成时封存终态。真实无比赛 Windows Job 烟测确认本机虚拟环境启动器可由进程身份识别；另一项烟测在原 Worker 的 `owned_writes` 守卫内验证了身份和终态检查，专属临时目录在进程退出后已清理。这是本机证据，不是任意平台保证或防恶意同用户的隔离。

投影经独立合成复核，额外覆盖各坐标收益不同、胜／平／负、跨批别名隔离，以及收益护栏和请求前缀的 true／false／unknown。此前缀与经济筛查仅决定下一步是否值得评估，不构成显著性或晋级。当前针对准备、入口、调度和投影共 38 项合成测试通过；父流程冒烟全部使用模拟对象，不等于真实比赛。真实绑定、登记后的 preflight 和正式游戏结果必须另行记录。
