# 单一学生条件示范采集：独立复核范围

一名独立子代理从 96 格结果重新计算比较分类、合格条件及角色／对手／时间窗口分布；核对已保留数据的索引、候选宽度、来源坐标和本地合同摘要。21 个合格窗口来自 14 场已消费比赛；它们并非 21 个独立随机样本。五个训练侧重复、七个跨拆分开发重复与最终 `21 = 7 + 2 + 5 + 7` 的账面关系自洽。

另一名独立子代理核对 16 个来源收据均绑定同一 baseline 检查点，验证两份本地 NPZ 的摘要、形状、类型、标签索引及保留坐标；按认证 checkpoint 的 mean／scale 独立重算原始和标准化 float32 整组输入，拆分内及拆分间未发现完全重复。依据保留组数和覆盖，事前数据门确实未通过。

本次独立复核没有重新读取全部 16 条原始轨迹或完整回放，也没有重做模型推理、官方单步或完整比赛。仅凭保留的两份 NPZ 和脱敏账本，不能独立恢复所有被移除样本的特征、重算完整去重闭包或验证冲突统计；不能仅凭同为 `step 15` 就断言各重复组的具体成员。结果中的比较和物理状态差异来自本次受审执行器的现场检查，账本不包含第三候选实际 ID 或完整下一状态。

运行器记录 192 次完成的比较和 384／384 的控制器调用／官方单步预留数；成功返回按代码路径支持这些调用完成，但没有独立外部逐次计数器。本轮会话的外层启动器观察到退出码 0，本地 `stdout` 与结果一致、`stderr` 为空且终态为 completed；退出码未另存为独立进程收据。登记与程序没有训练或晋级分支，没有单独的晋级审计收据。本机文件、摘要与 Git 提交不是第三方签名或时间戳。
