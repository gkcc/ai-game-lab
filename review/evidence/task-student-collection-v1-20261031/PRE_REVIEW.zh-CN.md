# 单一学生条件示范采集：运行前复核

独立子代理核对六个闭区间覆盖全部 719 个动作回合，采样排名只依赖公开角色、对手、席位和回调坐标，不使用真实 seed 或收益；旧 719 行完整来源扫描成功前不能读取排名样本。来源适配器继承旧登记、比赛收据、原回放和 trace 身份链，固定使用 baseline 学生及双方席位。

另两名子代理分别实现及独立复核数据整理：按已认证模型的实际标准化顺序比较 float32 网络输入，传递闭包内标签冲突整体排除，跨拆分重复剔除开发侧代表；这只排除整组完全相同的输入，不排除近似局面或其他关联。预审发现入口曾漏记不合格窗口，已修复并加上逐行数量对账；一项纯内存集成检查覆盖 96 个窗口、合格／不合格各 48 个及三种汇总数被篡改的停止行为。选中输入的特征名、顺序和 schema 均与认证 checkpoint 核对。

集合目标函数作为后续准备单独实现：条件教师单标签和教师／学生正例集合分别在同一验证集合上计算，并使用相同的冻结 baseline 全候选 KL；第三候选只表示行为对照，未知候选仅参与 KL，不被声称为已验证的差动作。独立审查对 35 组合成输入做有限差分，并复核 padding 和 JAX CPU 梯度；结果符合目标表达。JAX 正式训练仍需额外验证 host 输入、梯度及优化器状态，并另行登记。

采集、旧比较器、官方单步、来源与集合损失的相关回归合计 77 项通过；这些是合成和内存内官方单步测试，不代表本次真实采集、训练或完整比赛已经完成。旧来源认证会间接解析保留种子的私有排除库存；这些值不用于本阶段采样或模型输入。内存、时间和磁盘检查均按登记执行，实际运行与独立复核另行报告。
