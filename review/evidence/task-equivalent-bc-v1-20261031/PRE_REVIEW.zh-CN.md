# 条件行动监督：独立事前审阅

未参与实现的子代理审阅了登记、数据来源和种子隔离、教师续行、双臂损失、总入口、GPU 进程监督及输出范围。它发现并促成修正：停止原因被包装成普通错误、旧只读模块导入时把项目目录插入依赖搜索路径、引导文件未列为必备源码，以及新包同名模块遮蔽检查不完整。发布检查还阻止了公开源码中的本机显卡型号；设备完整身份现仅在本机预绑定并严格匹配，不进入公共汇总。单独的训练和数据复审还促成了历史教师前缀绑定、同一检查点导出绑定、未知候选掩码、padding 及信号清理边界回归。

独立审阅者用旧公开登记证据做数据绑定结构检查，未读取私人训练样本或模型。Windows 合成套件及后续针对性回归共 65 项，其中 64 项通过、1 项因 Windows 无 memfd 跳过；WSL 指定 CPU 的 10 项训练核心测试通过。真实 Linux pidfd 监督已用合成休眠子进程验证 SIGTERM 触发取消并回收。另实测 Windows 宿主到 WSL 的缺合同失败路径及会话回收；该测试为避免低于启动线时运行真实任务而注入宿主内存读数，未使用 GPU，不能证明实际启动内存达标。采用专属临时目录并在子进程关闭后实际清理。

事前审阅未发现尚须先修的确定接口阻断。它不证明真实样本可在时限内处理、资格门会通过、GPU 会执行训练或学习结果会改善。正式入口仍须先核验登记提交、公开源码清单和本机预绑定，启动时可用内存至少 5 GiB；资源检查为采样，不是硬实时上限。
