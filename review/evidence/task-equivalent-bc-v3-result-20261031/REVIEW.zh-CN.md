# 第三次条件行动实验：独立只读复核

独立子代理对照登记、外层退出记录、12 场采样进度、72 组续行汇总及阶段目录；核实退出码为 0、stderr 为空、训练门槛为 false，目录只有汇总，没有训练输入、GPU 产物或新模型，也没有该实验仍在运行的 Windows 进程。它重新核对 199 项源码清单的 Git blob、相关来源绑定、旧模型、默认 Bot、对手及两次旧现场摘要，与登记身份一致。

对聚合结果独立复算：训练角色分别 4 个合格组，开发角色 0 个，不满足开发至少 2 组；每个角色的已尝试正例、请求不同和 unknown 与备选尝试总数相加一致。这些是对入口汇总的校验；没有持久化逐组候选明细，也未重新运行教师续行或官方比赛，因此无法仅凭现有摘要独立重算每个分类。结果不能证明未尝试候选不等价，也不能证明真实比赛收益提升。
