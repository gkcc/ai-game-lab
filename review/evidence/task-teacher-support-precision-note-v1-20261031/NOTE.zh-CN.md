# 教师支持探针的特征比较精度补充

[原结果](../task-teacher-support-probe-v1-result-20261031/RESULTS.zh-CN.md)中 120 个目标支持、其中 54 个目标“特征不同”的计数保持不变；这里的相同／不同是对**已编码 shared 与目标候选数值的类型和值**做严格比较。实际 `bc_crop.features.encode` 先把 shared 特征转换成 float32，候选特征也先转换成 float32，再转为 Python 数值；因此这 54 组的比较并非对未经量化的高精度输入进行。严格快照会区分正负零，后续标准化还可能改变数值差异的表现。

原探针未保存逐组编码，现有账本与证书不能重算这 54 组有多少仅由正负零造成、标准化后是否仍不同，也不能判断是否改变模型选择或收益。历史 Replay 仍保留，另行登记并运行冻结探针可以重新生成所需比较。将来采集迁移示范时仍应保存 terminal 自身的候选编码并使用其候选顺序映射标签，再按实际训练精度检查重复与冲突。该补充不改变原支持计数，也不代表训练或竞技结果。

独立子代理复核真实编码路径后，另用合法 float32 合成数值验证：不同的已编码值经 float64 标准化再转换到训练用 float32 后仍可能重合；这只是解释精度边界，不能替代对那 54 个未保存实际样本的重算。另 66 组严格相同仅覆盖 shared 和对应目标特征，不保证整个候选集合或联合请求相同。
