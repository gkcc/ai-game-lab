# 两个冻结对手的任务教师接口：事前验证

上一阶段混合条件示范因 `MemoryError` 中止，未生成数据集或评估数据门；保留其唯一尝试及失败结果，不重试。本阶段换一个问题：现有 `market` 和 `round2` 规则 Bot 能否在自己的真实决策上下文中输出可审计的任务标签，同时逐回合重现其原始完整请求？这不是训练、新完整比赛或收益试验。

固定选择已完成 Anchor baseline 来源中匿名角色 A01 的四场旧回放：两名对手各交换 learner 双席。教师始终取 `1 - learner_side`，使用该教师自身的单方合法观测；因此四场覆盖教师双方席位，但仍然只有一个已消费 seed 簇，不能作为独立泛化证据。对手源码通过固定官方完成记录的 row → `rival_sha256` 重新认证，在内存中插桩；不更改已冻结源码、市场策略、作物策略或官方规则。完成来源为 Git 提交 `1610ee975de25c0c1afa7a34facd54f1904ee331`，官方规则为 `f994f2050d58d84f649329c1e35ce09ada7007c5`，规则文件 SHA-256 为 `bc8a54879ef02c7ea64b8b333d6a976f0ea65c4949149d01f463f23bccee653e`。

对每场已有 720 状态的回放，连续调用教师 719 次；比较记录帧中教师的完整 `farmer`、`hands`、`market` 请求，标量类型与列表顺序均必须一致。检查教师任务回调的候选唯一性、原 max 选择、标签所属、275＋98 特征 schema、单方观察和资源状态隔离。每组最多 256 候选、每回合最多 32 次回调，超限停止而非截断。所有检查通过且每场至少有一个回调才算技术验收通过；发生一次请求不符、输入异常、身份或资源错误即停止，不能按事后结果替换局面。

本轮不调用学生、不重跑官方状态转移；被读取的历史对局已有官方复演证据。本次只证明所测教师请求与历史记录吻合及其自身候选能被编码，不证明其所有任务已由官方实际执行，也不证明候选集合能被现有 terminal 学生控制器表达。回合中依次产生的任务机会并非独立样本；同一状态下的不同教师需以后单独核对候选及预留前缀，不能按 ordinal 强行对齐。

## 资源、来源与停止

一场一个独立具名 Windows Job，父进程串行等待、检查成员清空和进程回收后再处理下一场。各 worker 在读取来源前验证父进程身份、指定 Job 成员及唯一排他尝试；阶段失败或关闭后不得再启动。启动和每场之间可用物理内存至少 5 GiB，运行中采样下限 4 GiB；每场采样 RSS 上限 2 GiB、Job commit 上限 3 GiB，单场最多 900 秒、全阶段最多 3,600 秒，并为两段清理预留时间。内存、进程数与墙钟为采样及协作式检查，系统调用和调度不是硬实时保证；这些数值是实验限额，不是对本机硬件的公开测量。磁盘余量至少 4 GiB。

每场只在内存保留一个已认证 Replay，回合结束清空临时观测和回调记录，最多累计并公开匿名操作与候选宽度统计，不保存原始状态或新训练数据。`sources.read_game` 同时核对对应压缩 trace 摘要；来源上下文还读取已完成 Anchor／DAgger 面板与 fresh 已消费绑定的元数据以校验身份及 seed 不重叠。读取认证 checkpoint 仅用于 schema，不做模型前向；不读取未运行 seed 清单。旧 Anchor input／result 文件并未由四收据链直接封存，只作辅助语义核验。

结果先写 provisional；只有四个 case 的独占记录、Job 回收收据及结果被完整证书绑定后可消费。仅一次尝试，不自动重试、训练、启动 PPO、修改默认 Bot、提交 Kaggle 或覆盖旧实验。原始回放、模型、源码身份、私有 seed、进程信息、回调输入和日志均留本机；公开仅发布经检查的匿名汇总与证据边界。
