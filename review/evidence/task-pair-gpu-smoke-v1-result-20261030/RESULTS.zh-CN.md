## 证据边界

- 外层退出码和监督器的脱敏结果由操作端观察；设备、梯度、更新、会话及管道判定来自冻结程序与监督器的执行结果，不是独立操作系统 GPU 活动监控。
- 本次登记的 `run.py` 在调用结果检查处的注释将损失和梯度误写为更新前后都检查；实际 `fit_core` 只在更新前检查这两项，更新后检查新参数和优化器状态。该注释不改变运行逻辑；本证书保留当次源码身份并以实际代码为准。
- 子进程原始令牌收据未单独保存；事后审查只能核对登记源码、脱敏结果、操作端记录及预先做过的合成反例，不能重新验证当次原始令牌。令牌管道不认证写者 PID，也不防同用户恶意伪造。
- 135 秒只覆盖 Linux 子进程监管及清理，不包括监督器本身的引导和收尾；内层及工作时间门槛是采样式约束，不是单个 GPU kernel 的硬截止。
- 运行前后源码比较和私有尝试标记不是并发文件锁或第三方时间戳；第三方依赖供应链未独立认证。自有会话检查不代表对其他系统进程的全面监控。
- 私有设备名称、原始输出、令牌、输入、模型和本机路径没有作为本证书发布；本地排他尝试记录与公开投影分开保存。旧证书与默认 Bot 未更改。
