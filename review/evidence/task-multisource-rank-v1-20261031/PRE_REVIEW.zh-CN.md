# 运行前独立复核

独立复核者分别检查跨任务排序核心、评估器、数据去重和入口。纯合成 CPU 测试实际完成 64 次同步更新，并将带掩码的 CE＋KL 梯度与独立概率公式比较；零残差、来源配平、非法输入及跨任务选择有针对性回归。评估器的选择、分组计数及 NLL 另用合成样本独立核对。

针对复审构造的反例，入口现在排除单候选和标准化后候选行完全相同的组，分别记录覆盖；旧非浇水覆盖不足为 unknown，已观察到的退步仍优先失败。来源去重按两种表示做传递闭包，哈希碰撞逐字节核对，标签冲突整分量剔除；入口先将数组复制到不可写缓冲。评估汇总核对角色与目标类别交叉分区，覆盖及精度转换收据在门槛判断前留存，成功封存时重新核对。以上只覆盖合成反例及代码契约。

入口的作业身份、数据范围、异常封存和权限验证经过纯内存替身审查；尚未执行真实 Windows Job、真实数据前向或本轮训练。原始数据、采集前的并发变更、相关游戏状态与模型竞技能力不由这些回归证明；本轮结果须另见运行证据。已有 GPU 失败登记保留，本实验不补跑该尝试。
