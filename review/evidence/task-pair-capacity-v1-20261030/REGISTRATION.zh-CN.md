# 已失败玩具冒烟的只读容量分析登记

本阶段不运行比赛、不重试旧面板或玩具冒烟、不训练、不更改任何预算；仅描述 `78f14984f32ef68028fd1a8798c51d51e027cb81` 已公开失败证书所指的本地玩具 trace。合成模型和合成种子仅用于工程冒烟，不能代表真实策略、一般对局或竞技表现。这份登记发生在原失败和少量人工查看之后，是描述性复查，不是事前独立实验或第三方时间戳。

登记前建立仅在本机保存的身份绑定，核对原有 16 个失败产物的大小与 SHA256；该事后绑定不防同用户篡改，不是第三方证据。先将本登记、分析代码及合成测试提交，再读取该 trace 计算本次预设统计；文件名、大小和 SHA256 使用此前的本机清单绑定，不公开私有摘要。分析经摘要核对的有界不可变压缩快照，再重新核对原文件描述符；这防止解析时文件切换导致误用未绑定字节，但不声称能阻止同一用户篡改所有本机证据。原失败产物保持不变。此前已知道 580 条、最后一步 579、最后三条任务行数、末尾累计计数及最初 211 行剩余额度，所以不声称对这些事实是盲态分析。

本阶段的 `learning/task_pair_capacity_v1/entry.py` 读取本机绑定和原失败清单，核对失败登记身份、16 个文件的大小与摘要，并确保清单中唯一的压缩 trace 与本机绑定一致；分析前后均复核文件和清单。输出目标必须不存在且位于输入产物根目录外，以免覆盖或增加历史产物。入口只是本机完整性检查，不构成独立公证，也不抵御同用户并发篡改路径。

入口限制压缩文件至 128 MiB、单行至 8 MiB、解压总量至 512 MiB；按 0–579 精确验证 580 条、无额外解压字节、错误标记为零、计数与逐回调差额一致且不超过原限额。本次启用任务模型，作物模型调用次数也不应超过任务模型调用次数；任务调用数为零时行数必须为零。gzip 允许原格式的多个成员及末尾零填充，全部压缩字节仍受摘要绑定。失败即停止，只有完整且核验通过的结果才可发布；写入出错可能残留不完整文件，不能视作有效结果。这些读取限额不是峰值内存或硬时限。输出仅包含固定六个区间 0–99、100–199、200–299、300–399、400–499、500–579 的回调数；逐回调任务/作物调用数、输入行数及合计行数的总和、均值、中位数、最近秩 95 分位数、最大值；各区间末尾的累计计数、剩余行数和原固定限额。结果不能包含轨迹、种子、身份、路径、模型摘要或逐步私有状态。

统计只是已完成 Agent 回调的工作量，不证明同数官方状态转移；后续回调和抛错时实际输入没有记录，不能推断完整 719 回合所需容量，也不能据此认定失败根因或提高预算。成功标准仅为身份、边界、计数验证和脱敏汇总通过；任何故障原样保留并停止。
