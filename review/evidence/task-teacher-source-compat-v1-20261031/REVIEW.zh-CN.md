# 独立复核：历史教师训练来源

第二名子代理只读比对两份明确的旧训练档案与事前公开身份承诺，单独读取其 seed 元数据，核对四个旧已消费簇与本次训练／开发角色不相交。两份旧 schema 的原字节、登记身份和维度一致；该复核者没有独立读取当前基线模型元数据，旧 schema 与当前基线的语义一致性来自第一名核查者。

5,104 组及五类目标计数来自历史公开登记，未在本轮解码和重算标签；内存数字由数组维度估算，不是峰值实测。两次核查都没有进行模型前向、训练或比赛，也没有重算跨来源特征重复及标签冲突。

读取边界如主说明所述：有一次查看公开历史说明意外见到两个当时预留的 seed，是否已消费未知；另一次工具输出回显旧已消费训练 seed。这些字面值不写入本轮结果、参数或比赛；未来新鲜独立测试须排除已暴露的预留值。
