# 独立复核与证据边界

两名独立复核者调用本机封存入口，分别核对事前登记、来源／基线身份、单次 attempt、Job 清理、参数快照及结果计数。一人按封存摘要独立复算角色和目标类别分区、去重过滤的数量关系及筛查结果；另一人检查训练与诊断索引核验次序、双宽数值检查和 64 次 CPU 更新声明是否与冻结源码及收据一致。Job 零退出且成员清零；资源采样不是硬实时上限。

他们没有重扫原始轨迹或教师档案，也没有重新计算逐组模型前向、重新训练或运行比赛。42／48 学生索引、数值门、双宽对照及 64 次更新由本机 worker 收据和冻结代码支持，并非本次独立重复计算；本机封存也不是第三方签名或不可篡改时间戳。

新诊断数据的角色级一致／分歧和操作汇总在本实验前已被观察；旧诊断可能早已进入冻结基线的训练来源。本次没有新的独立评估，预登记筛查失败不能通过旧诊断的一次改正改判通过。
