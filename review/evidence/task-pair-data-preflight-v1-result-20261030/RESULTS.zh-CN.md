# 两臂任务 BC：真实数据预检结果

事前登记提交 `27635128cee4653e661faeaa16aab28e3d78fc5f` 后，登记 Git 原字节和源码身份的只读预检通过；唯一真实入口执行由操作端观察到退出码 0，并写出完整粗结果及本机私有掩码清单。运行器对原教师训练缓存和两类已消费开发数据完成身份及结构检查，复现历史记录的 **3,978 个原教师开发决策组与训练数值输入重合**、跨这两个来源的标签冲突为零。该数字是决策组数，不是独立对局数；旧报告的非零冲突以不同数值组计，本预检以开发决策组计，只能比较零／非零。

对训练数据、原教师开发数据及条件教师开发数据，教师选中 `PLANT`、且同目标有至少两个不同单位候选的主要数据门槛，在**全部组**和开发数据的**未与训练数值输入重合子集**均达到登记条件。条件教师旧、新两个来源也分别达到对应主要门槛。两类开发数据与训练数据均存在至少 20 个数值重合组；预检未发现这两类跨集合匹配中的不同教师标签。未比较两个开发池彼此的数值重合，也未据此宣称完整游戏状态相同。

操作覆盖使用教师选中该操作的组数与簇数粗分档：训练及两类开发数据汇总的 `DIG`、`FERTILIZE`、`HARVEST`、`PLANT`、`WATER` 均达到各自粗门槛；但条件教师**旧来源的 `DIG` 在全部组与未重合子集均为 `unknown`**。`unknown` 不是通过；达到门槛只说明选中该操作的组数与簇数满足粗条件，不能保证其他指标有合适分母、不同操作直接竞争或评估稳定，也不代表策略优秀、官方动作空间完整、样本独立或游戏收益提高。

一名独立子代理核对登记绑定、保存结果、九个私有掩码的摘要、类型和长度，以及掩码聚合与历史重合记录的一致性；它没有从源数组独立重算全部分簇门槛或数值匹配。另一名独立子代理事先固定三个开发分片各三个位置，直接比较完整有序数值输入和标签，九组的三类掩码一致；数值重合与 `PLANT` 资格各覆盖真、假，标签冲突只覆盖假。该抽样未复用预检的哈希分桶，不能证明全量结果或独立复现 3,978；它未重新对原缓存全部文件做摘要校验，且无操作系统级并发锁。

两类开发数据均已参与历史研发，部分条件教师状态由早期模型参与生成；它们不是独立留出。数值匹配按组宽、共享特征和有序候选特征比较，规范化带符号零，摘要命中后另行逐块数值比较；这仍不等于完整状态相同。预检未重读官方原始观测，无法单凭本结果证明单位真实存在、动作合法或机会集覆盖官方完整动作空间。粗阈值和公开的冲突存在性不提供形式化匿名保证；私有分层掩码、来源数据和种子不发布。

本阶段未加载检查点权重、评分、训练或新增比赛；这由执行路径和复审范围支持，并非系统级文件或 GPU 活动监控。前后源码校验不是操作系统锁，缓存先校验再映射，不能排除同用户并发替换；时间及可用内存限制为采样检查。入口的结果写入限定在本次独立产物目录；本次 Git 变更未修改默认 Bot 与已跟踪历史，未逐项哈希核验所有本机历史产物。数据预检通过不自动批准模型或教师晋级；后续如开展小规模两臂训练，需另行冻结对照、训练预算、开发指标和停止条件。
