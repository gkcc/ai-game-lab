# 市场对手开发对照：登记前复核

独立子代理审查了已消费种子选择及公开 JSON 留出角色扫描，发现并协助修复嵌套分组、`seed_number`、数字键统计、跨训练／验证重叠和未扫描的跟踪 JSON 等具体问题。候选的旧重建坐标经固定验收／账本摘要链检查；扫描不覆盖未知私有文件，也不能将历史执行方重建夸大为全部独立复演。

另一名独立子代理核查新入口与既有 Worker、资源监督和配对投影，发现并协助修复比较收据未绑定、总时限未包含准备阶段、汇总重复保存大事件以及入口导入前未检查内存等问题。它独立运行 16 项合成测试、隔离运行环境导入冒烟和 Windows 内存只读检查；未读取真实种子或模型，未启动比赛。

主代理在本机预绑定前完成只读身份预览，并在独占写入后用相同盐与来源重新计算完整私人绑定，一致；随后运行新入口及既有协调器、投影、验收与子任务的 46 项合成测试，均通过。该本机操作不是第三方证明。登记提交后的完整 `--preflight` 和真实比赛结果须另行报告。
