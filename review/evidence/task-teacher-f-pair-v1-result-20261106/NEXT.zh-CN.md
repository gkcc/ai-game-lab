# 下一阶段范围建议：候选集合感知的任务解码

这是一份基于本轮结果的下一阶段设计建议，尚未实施或登记新的比赛。八例单次教师替换没有正收益，不支持以这些案例继续强化模仿，也不足以构建收益预测训练集；它不否定完整教师策略。

下一阶段只研究当前任务候选之间的竞争关系。现有任务网络逐候选评分，控制器每次选一个 ID 后删除已选单位及同地块任务。合法观测、单位及目标身份已经存在于回调接口中，试验不需要读取对手私有信息，也不需要增加神经输入或改动冻结权重。

建议创建独立解码器：每回调照常执行并计费一次原网络前向，使用它已计算的 logits；在当前可用单位和地块之间，先最大化可分配数量，再最大化分数和，平局按公开候选 ID 定序。只返回匹配中的一条，随后由原控制器更新资源与候选，下一回调重算。这样避免负 logits 导致全员等待，也不缓存整回合计划。它不等于整回合最优联合动作，更不把模型分数解释为现金价值。

“一单位一地块”继承当前教师的预留政策，不能宣传为官方永久合法性。种子、肥料、仓容、运输与导航仍通过原控制器；匹配不得绕过真实回调中已更新的资源条件。记录应分别保留网络原首选与解码器选择，保持实际前向和候选计费。

最小验证范围拟定为：

- 一个两单位、两目标、剩余两次日内行动的官方可执行场景，比较贪心与联合分配的实际动作和作物状态。测试分数是夹具，不是训练结果或真实网络效果。
- 少量稳定不变式：单单位等价、负分和平移、单位及地块互斥、每回调恰好一次前向、资源变化后重新读取候选。
- 技术验证通过并另行登记冻结后，仅使用已经消费的 F01／market、F02／round2 各双席，共四场新完整比赛与四次主复演，复用认证旧基线。两个“种子—对手组合”不能拆成独立对手效应。
- 明确区分 ID 变化、完整请求变化、官方状态变化和最终收益。初筛没有执行变化或没有正向收益迹象，就封存负结果，不追加距离权重、温度或更多 seed 追求通过。

新的完整源码、微场景事实、资源上限和数值验收门必须在实际面板前单独冻结。此文不冒充已完成实现或实验登记。本阶段建议不训练、不使用 GPU、不启动 PPO，不改默认 Bot、冻结模型或既有经营规则；目的只是验证既有神经评分能否通过更完整的分配解码产生实际经营作用。是否改善收益仍待实测，也没有证据说明此瓶颈造成了本轮八例的结果。
