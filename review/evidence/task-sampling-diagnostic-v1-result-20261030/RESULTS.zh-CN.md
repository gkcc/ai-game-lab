# 冻结任务模型的入批采样：离线诊断

本次只读取两份登记训练档案的原始字节用于摘要校验，并解码组偏移、教师标签和候选操作三个元数据成员；没有解码特征、游戏种子或模型权重，也未读取留出轨迹。源码经两个子代理在合成数据上预审后运行；源码和结果在同一批提交，不是第三方事前时间戳。

5,104 个训练组的候选宽度均不超过 256。旧训练器每批最多 256 组，padding 预算为 65,536；因此对于这批数据，任意排列在选满前都不可能因宽度预算跳过组。旧规则等价于取排列中的前 256 组；在理想均匀排列模型下每组入选概率相同。这个数学结论来自训练元数据的宽度上界，不依赖某一次随机重构。此处的等价是对同一排列的选组规则而言，并不意味着另一随机流选到相同批次或得到相同权重；随机流、批次顺序和微批浮点累积都可能改变模型，本次没有训练，无法判断方向。

按冻结旧→新顺序、模型初始化随机数消耗及登记的 NumPy 版本条件重构的 128 批全部为 256 组，共 32,768 次组曝光，跳过 0 组。历史收据没有实际批次索引或 RNG 状态，不能把重构结果说成当时直接记录。另一个同主种子派生的伪随机域按相同每批组数做一次对照：类别曝光在有限抽样下有波动，不能把两条流的差异当作系统性偏差或训练收益。

两名独立子代理只读核验：一人从三个允许成员独立重算全部汇总，另一人只读取组偏移并独立推导宽度上界；后者此次没有重新哈希整个档案，身份依赖此前检查和执行时快照。两人均未调用模型、训练或运行游戏。10 项合成回归覆盖宽组拒绝、损失权重、格式、身份快照及隐私边界；进程退出码为 0，结果原始 SHA256 为 `d5caa472051a76c02cb0e620f389d6f92c094e50bbb2079a455211ca16b69419`。

结论：**停止以修复该数据集的宽度跳过偏差为理由训练新模型或启动新比赛。** 这不证明模型能力已充分，也不排除教师示范、动作类别分布、标准化或其他因素造成的限制。原始模型、默认 Bot、规则和历史结果均未更改；本次无 GPU 运算。小类抑制与已知敏感值扫描不构成形式化匿名保证。
