# WSL 空载内存观察（事后诊断）

在浇水残差 GPU 尝试已经停止并封存失败证据之后，另行启动一次自身拥有的短时 WSL 空操作，等待其正常退出；没有加载模型、访问数据、使用 GPU 或重试训练。Windows 可用物理内存以约 0.2 秒间隔采样，共 81 个样本。该次空载观察中没有采到低于 4 GiB 的值，但大部分样本低于 5 GiB；这是一次时点相关的观察，不保证以后启动相同，也不包含 JAX 的额外内存开销。

系统同时存在其他负载，不能将全部可用内存变化归因于 WSL，也不能把该次空载结果作为先前失败时瞬时内存或清理状态的证据。采样值和精确时间未以逐点日志保存，以上只记录交互运行所得的脱敏汇总；这是事后诊断，不是预登记的训练或独立实验。该空操作只等待自身 transport 自然退出，没有关闭整个 WSL 或结束其他进程。
