# 下一阶段：单次选择到官方终局回报，四对采集小试

这是独立规划子代理基于公开源码及维护者提供的完整结果提出、维护者核实后采纳的建议，不是 WebChat 意见，也不是下一轮完成报告。当前接口能执行93次新收获，但四例平均自身收益下降2,046，两个 round2 案例胜转负。保留接口和所有权重，不调收获偏置，不晋级，不立即训练。

唯一推荐是建立小型 `task_harvest_return_pairs_v1`：验证“学生实际访问状态→一次真实 selector 选择→官方终局目标”的数据采集链。旧教师缓存只有单个 `teacher_label`，训练是全候选组 softmax 交叉熵；不能把老师原来无法表达的新选项一律当负项，也不能把一局输赢回填为该局23／24个动作的标签。旧四个48步差同样不是终局监督。

## 固定取点和干预语义

从本轮四条完整新轨迹各取一点：按 `(step, callback ordinal, unit, y, x)` 选择最早“实际选中新 HARVEST，且同单位同地块 WATER 仍在候选中”的记录。先登记选择规则、来源和运行器，绑定实际选点后，在提交冻结之前不执行反事实。缺失就记录缺失，不补点、不看收益挑点。四个来源仍是消费过的开发数据，不称新留出；不读取新种子库存。

使用独立的选点协议。旧 `task_harvest_unexpressed_v1` 目标要求原动作不是 HARVEST、ordinal为0，语义不适合这里；不得为复用旧 schema 偷改实际选择或序号。

每点两个臂：H保持本轮事实选择，W只在绑定 callback 返回对应 WATER。两臂均经过既有任务槽消费、资源预留及完整动作生成，然后继续同一扩展任务模型和同一选种模型到DONE。允许该次选择自然影响同回合后续单位、市场和未来状态。不得在完整请求产生后替换一条单位动作。

原网络提议、实际干预选择和最终请求必须分别记录。W是实验干预，不能伪装为模型原始 argmax；本轮生产适配器的“实际选择等于模型提议”断言不可直接套给该记录，也不得修改已冻结适配器来消除断言。

## 回报与验收

每对保留相同合法输入及H／W两个候选、双方终局现金／净收益、现金差和比赛得分。主要连续目标是 `margin(H) − margin(W)`，同时保留自身净收益差；目标冲突时明确标记，不强制合成单一好坏标签。它是特定后续策略和冻结对手条件下的局部回报，不是最优价值函数。未来结果、对手私有信息、真实种子及对手身份仅用于离线索引／目标，不能进入部署特征。

每对先完成H事实臂，验证719次本方模型调用和目标后全部官方状态复现本轮对应完整比赛，含顺序、完整请求和终局奖励。通过后才执行W。核验原点输入相同、两候选可执行、覆盖恰好一次、实际单位效果、双方DONE、零错误及全部费用。任一身份、事实复现、资源或执行失败即封口，不重试、不补点、不改阈值。

## 有界实现

复用已验证的官方恢复入口、保序比较器、Windows Job、预算与独占证据写入。旧48步核心硬编码了 horizon、验收计数及末态；终局续行必须新建薄入口和必要回归，不能热改常量后声称已验收。重点回归 selector 干预确实改变正常预留路径，并准确分开模型提议和干预执行，不扩建审计平台。

四对共八条后缀。官方动作预算为 `Σ 2×(719−目标step)`、最多5,752；每臂重建前缀再续行，本方及对手调用分别最多5,752。任务／选种前向最多32,000／64,000，输入行最多1,280,000；禁止偷偷追加额外模型轨迹或评分。八次恢复的环境构造、初始化须按真实入口另行冻结计数，不能沿用本轮 make→run 的十二次初始化。串行、每对最多900秒、总两小时、新输出最多1 GiB，沿用已有内存门槛。以上均须在新登记中落实为可检查预算。

四对只足以检验回报样本生成链，不足以训练可推广的偏好网络。通过后再另立按完整比赛／种子分组的有限采样和一次学习实验；GPU届时用于实际批量权重优化。本小试不训练、不做 DAgger／PPO、不改变默认 Bot，也不把旧分类准确率或这四对表现当独立策略进步。
